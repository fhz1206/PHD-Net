# PHD-Net 竞争力与脑同构性评估

> **适用范围**：与 Transformer / MoE 的**对比结论**，以及与人脑的**逐项机制对照**。
> **不写**：任何性能数字（唯一出处 = `PHD-Net_性能评估与迭代方案.md`）、机制实现细节
> （=《架构设计》）、优化项状态（=《对标 Transformer 优化路线图》）。
> **数据截止**：2026-09-30。
> **诚实前提**：本文的"竞争力"均在**本机 CPU 资源受限**与**窄任务**前提下成立；
> 100B 外推是**假设驱动的情景推演**——PHD-Net 目前**没有实测缩放曲线**。

---

## 一、结论先行

| 问题 | 一句话结论 |
|---|---|
| 通用语言能力能否对标前沿 MoE 大模型？ | **不能，且差距不由参数容量决定**——差距来自经验量（10⁸×）与表示学习机制；把容量放大只会放大容量，不会自动转化为能力 |
| 放大容量的胜场在哪？ | **单步计算量少 4–6 个数量级、本机 CPU 可跑、在线单样本、无灾难性遗忘**——这四项与规模无关，是结构性差异 |
| 放大容量的风险？ | 会：**容量单向扩容已被实测证伪**（见 §2.5 悲观情景）；扩容必须同时解决"谁来用这些突触" |
| 最关键的一条结论 | PHD-Net 不缺算力预算，**缺的是能把容量转成能力的可塑机制**——五项表示层改进全部为负，这是当前架构的真正瓶颈 |
| 与人脑架构是否相同？ | **不能称"相同"，可称"机制同构"**——模块有明确神经认知对应，但规模差 4–5 个数量级，且**稀疏性上有一处明确欠账**（§四） |

## 二、与 Transformer / MoE 的对比

### 2.1 先解决口径：两种"参数"不能直接比大小

两者说的"参数"是不同物理量，直接比大小没有意义。必须拆成三种记账口径：

| 口径 | 含义 | 前沿 MoE（以 GLM-5.3-Flash 320B-A18B 为参照，引用） | PHD-Net（100B 突触口径） |
|---|---|---|---|
| **存储参数**（权重文件里存了多少数） | 需要持久化的数值总量 | 320B（FP8 ≈ 306 GiB / BF16 ≈ 640 GB） | 100B 突触槽（实际只存**已生长**的条目） |
| **激活参数 / 每步触碰量**（处理一个 token 要动多少数） | 单步实际计算规模 | 18B（288 路由专家 + 1 共享，top-8 激活） | ≈ 5×10⁴ 突触/步（推算，见 2.4） |
| **稠密可训练参数**（端到端接收训练信号） | 参与优化的参数 | 320B 全部可训（反向传播） | LM 栈 **≈0.2M**（M5 配置 1.24M）；100B 突触只有被触碰的才更新 |

**这张表已经说明了一半的结论**：MoE 用 320B 存储换取每 token 18B 的激活计算；PHD-Net 用
100B 容量换取每步 ~10⁴–10⁵ 的事件触碰。**两边都在做稀疏化，只是稀疏的维度不同**——MoE 稀疏在
"专家路由"，PHD-Net 稀疏在"事件驱动的局部突触"。

### 2.2 对标对象事实卡（GLM-5.3-Flash，**引用**公开资料，2026-08-26 发布）

| 项 | 数值 | 性质 |
|---|---|---|
| 架构 | MoE；总参数 **320B** / 激活 **18B**；语言 45 层 | 引用 |
| 专家 | 288 路由专家 + 1 共享专家，**top-8** 激活 | 引用 |
| 注意力 | KDA 线性注意力 + NoPE 稀疏 MLA 混合，支持 MTP；注意力计算约 3× 更少、KV cache 4.4× 更小 | 引用 |
| 上下文 | 1,048,576 token（1M），最大输出 128K | 引用 |
| 模态 | 原生文本 / 图像 / 视频 | 引用 |
| 预训练 | **30T token** 多模态语料；原生 FP8 | 引用 |
| 能力 | AA 综合智能指数 **57**；Terminal-Bench 2.1 **84.3**；DeepSWE v1.1 63.4；AutomationBench 48.8 | 引用 |
| 部署 | 全量 FP8 需多卡（社区实测 8×H20 可跑 512K 上下文） | 引用 |

> ⚠ 全部为**引用**性质，未经本地复现；PHD-Net 侧无任何一项可与之在同一 benchmark 表上比较
> （原因见 §2.6）。

### 2.3 PHD-Net "100B" 的三种定义（不明确则外推无意义）

| 版本 | 结构 | 稠密可训练参数 | 说明 |
|---|---|---|---|
| **A 容量版** | 事件驱动突触表扩到 100B 槽（如 N≈2³⁰ 神经元 × m≈93 出边），**LM 栈保持当前规模** | ~0.2M | 只扩书架不扩读者；**已被实测判定为无效路径** |
| **B 同比例放大版** | 容量 100B + LM 栈同比放大（n_top 128→4096、n_sdr→1024），靠稀疏 PC 压住 O(n²) | ~20M | 需要同量级的经验填充才有意义 |
| **C 完整版** | B + 经验填充到 10⁸–10⁹ token + 检索融合 + 全模块 | ~20M + 100B 容量 | 乐观情景的前提；本机不可达，需集群 |

### 2.4 资源与效率维度（推算）

**每步触碰量**（版本 A/B 相同，取决于 SDR 活跃位与每维哈希索引数）：

- 每步线索 = n_top(128) × k_hash(4) ≈ **512 个源索引**；每源出边 m≈93 → **≈4.8×10⁴ 条边/步**；
- predict + learn 两遍 → **≈10⁵ 次乘加/步**，即 **~2×10⁵ FLOPs/token**（量级估算，±1 个数量级）；
- 对照 GLM-5.3-Flash：18B 激活 × 2 ≈ **3.6×10¹⁰ FLOPs/token**。

> **差距：约 5 个数量级**（保守区间 4–6）。这是 PHD-Net 唯一不依赖任何假设就能成立的结构性优势。
> 实测口径见《性能评估与迭代方案》。

| 维度 | PHD-Net 100B（推算） | GLM-5.3-Flash（引用/推算） | 判定 |
|---|---|---|---|
| 存储 foot print | **已生长条目数决定**：真上 100B **必须迁移到 CSR/扁平数组**（1B 档在线 CSR 已落地，详见《架构设计》与《对标路线图》O3）；100B 规模客观受限 | FP8 306 GiB 常驻 | PHD-Net 结构优；100B 规模客观受限 |
| 单步延迟 | 事件驱动 O(1) 哈希，**与容量解耦** | 每 token 需读 18B 激活权重 | **PHD-Net 优约 1 个数量级**（CPU vs GPU 集群）；实测口径见性能文档 |
| 训练算力 | ∝ 经验 token 数 × ~2×10⁵ FLOPs | ≈ 激活参数 × token 量 × 6 FLOPs | **PHD-Net 优约 10 个数量级**（但不在同一能力点） |
| 训练数据量 | 当前冻结内部语料 27,034 字符 | 30T token | 差 4–8 个数量级 |
| 上下文 | WM 有界槽（4–8）+ 情景缓冲串行链；**无位置编码**，长程依赖靠联想链 | 1M token 窗口内直接访问 | **MoE 优**（结构性劣势，见 §三 B4） |
| 硬件门槛 | 本机 CPU / 12.6 GB 内存可跑 | FP8 多卡集群；最低部署亦需 8×H20 或 2×A100-80G | **PHD-Net 优多个数量级** |
| 在线持续学习 | 天然支持，**BWT +0.000** | 无原生在线学习；微调伴随灾难性遗忘（对照 −1.000） | **PHD-Net 独占** |
| 单样本记忆 | 一次印迹，30% 噪声线索下 **100%** | 仅 in-context（受窗口长度约束） | **PHD-Net 独占** |
| 多模态 | 无（单通道符号输入） | 原生文本/图像/视频 | **MoE 独占** |

### 2.5 能力维度：三情景外推（**估算**，非实测）

**必须先承认的方法学事实**：PHD-Net 目前只有**两个数据点**（0.2M 稠密 LM 栈、1B 突触容量），
**没有 scaling curve**。因此以下不是预测，而是"如果满足这些条件，大大致落在哪个区间"的情景推演。
基线锚点见《性能评估与迭代方案》（**本文不复制 PPL 数字**）；Transformer 参照的 loss scaling
经验指数 α≈0.34 属**借用于 Transformer、未对 PHD-Net 验证**。

| 情景 | 配置 | 关键假设 | 对应地位 |
|---|---|---|---|
| **悲观（证据最强）** | 版本 A：单独把容量堆到 100B | 实测类比：容量扩容不产生 PPL 收益，且更慢 | 连"十万分之一"都谈不上；仅得到一个巨大的空书架 |
| **中性** | 版本 B：容量 + LM 栈同比放大到 ~20M + 经验填到 10⁸ token + 内容寻址 / 回放稳定读出 | 表示层保持冻结（η_pc=0）；内容寻址 −1.6% / 回放稳定读出 −1.4% 可复现；按 Transformer α 折半兑付 | 约等于"0.1–1M 参数稠密 Transformer 在同语料"的水平；**仍低数个数量级的能力层级** |
| **乐观** | 版本 C + **必须先打破"冻结表征"约束** | 需先把五项失败的表示层机制之一做成正收益 | 接近现代 LLM 在小领域语料上的水平；**但这是当前的已知卡点，不是推演结果** |

**这条表格最重要的一列是"关键假设"**。把 100B 变成能力的不是容量，而是三个尚未兑现的前提：

1. **经验填充**：100B 突触按当前每 step ~10⁵ 触碰量，填满需要 ≈10⁶ 步以上连续学习
   （当前全部实验只在 10³ 步量级）；
2. **表示层可塑性**：五项表示层改进全部为负（冻结语料 +18.4%～+62.9%），"冻结表征"是
   多轮一致结论；不开这个锁，容量只能当索引表用；
3. **检索/融合规模化**：~~T3.2 是当前唯一稳定的正增益~~ **已证伪**——四轮增益
   −2.4% → −0.65% → −1.1% → **+3.2%（有害）**，符号翻转证伪其稳定性；当前稳定正增益为
   T3.4 内容寻址与 ② 回放稳定读出，其在 100B 容量下能否兑现**完全未被验证**。

### 2.6 判定矩阵（哪些维度能赢、哪些必输）

| 维度 | 判定 | 依据 |
|---|---|---|
| 通用语言理解 / 生成 / 指令遵循 | **必输**（不是分数低，是任务形式不可执行——无词级语义接口） | MoE 的 AA/Terminal-Bench 分数；PHD-Net 在这些基准上记为 0 |
| 长上下文（≥10³ token） | **必输**（结构性） | 1M 窗口 vs WM 槽 + 串行联想链 |
| 每 token 计算效率 | **赢 4–6 个数量级** | ~2×10⁵ vs 3.6×10¹⁰ FLOPs/token |
| 训练算力成本 | **赢约 10 个数量级** | 成本 ∝ 经验量而非容量 |
| 部署门槛 / 硬件可得性 | **赢** | CPU 可跑 vs 306 GB 显存多卡 |
| 在线持续学习 / 灾难性遗忘 | **赢（独占）** | BWT +0.000 vs −1.000 |
| 单样本关联记忆 | **赢（独占）** | 100%（30% 噪声线索） |
| 脑机制同构性 | **赢（独占）** | 逐项对照见 §四；MoE 路由无生物对应 |
| 多模态 | **必输** | PHD-Net 单通道符号输入 |

> 100B 的 PHD-Net 不会成为前沿 MoE 的替代品，而是一个**完全不同生态位**的系统——它们卖
> "能力"，PHD-Net 卖"学习方式与资源效率"。把两者放在同一张 benchmark 表上比较，本身就是
> 口径错误。

### 2.7 生态位结论

PHD-Net **不能替代通用 LLM**。价值场景是：资源受限设备上的持续学习、少样本关联记忆、
流式数据的事件驱动建模，以及作为 LLM 的**可学习记忆外挂**（LLM 管语言能力，PHD-Net 管
在线记忆与适应，互补而非替代）。

### 2.8 要让预估可证伪：必须先补的三组实测

1. **PHD-Net 的 scaling curve**：固定经验量，扫 3–4 个容量点，看 PPL 是否下降——**这是本文
   全部外推的唯一证伪手段**。已有部分结果见《对标路线图》O7（结论：当前瓶颈是数据预算而非
   参数规模），但容量轴的点仍不足以拟合曲线。
2. **锁定 100B 在线结构**：把 dict 邻接表迁移到 CSR/开放寻址，实测 10⁷–10⁸ 突触量级的
   单步耗时与内存——不解决这条，100B 连工程上都站不住（1B 档已落地，见 O3）。
3. **寻找正向的表示层可塑性机制**：在受控条件下逐一测试「更慢的稳态缩放率 + 更强调结构性的
   生长 + 生成式回放」的组合，把五项负结果翻出至少一项正值。

## 三、对标结论沿用（哪些差距是结构性的）

这一节的判断来自《对标 Transformer 优化路线图》，此处只保留跨文档复用的结论，**不重复数字**。

| 瓶颈 | 现状结论 |
|---|---|
| 任务信号止步末端 | **未解决，仍是主瓶颈**。三条同源路径（T1.1/T1.2/T1.3）无效；专项 10 配置实测判定**表征可塑当前不可解锁** → 冻结表征是必要条件 |
| 输入表示非学习 | 部分缓解（M7 词涌现贡献最大；可塑词典实测有害） |
| 主干容量小且与容量栈脱节 | 稀疏 CSR 主干 + 1B 容量栈已落地，但**LM 栈与容量栈的完全统一**仍未完成 |
| 上下文整合通路弱 | **已由记忆通路补上**（WM 真贡献 + 再入连接正增益） |
| 优化器原始、无自适应 | 微弱正增益，仍近噪声带 |
| 时序窗窄、无多尺度 | **M3 STDP 在 LM 路径上近乎零贡献**——长程依赖实际由 WM/LTM 通路承担 |
| 统计效率低 | `minibatch_size` 已实现，但在单遍预算下**有害** → 需配套多 epoch 协议 |

**总判读**：PPL 增益**全部来自检索/记忆通路**；表征可塑性五类尝试**全部为负**。

## 四、人脑架构对照：确认"相同"还是"同构"？

**直接回答**：不能确认"与人脑架构相同"；能确认的是**"机制级同构的功能性缩比模型"**
（brain-inspired / mechanism-isomorphic）。它复制的是大脑的**信息处理原则**（稀疏、局部、
事件驱动、双速率、预测、联想），而非大脑的**物理实现**。

### 表 A：机制同构层（逐模块；9 项机制级 + 4 项功能级）

| 模块 | PHD-Net 实现 | 大脑对应 | 层级 |
|---|---|---|---|
| M1 稀疏编码 | k-WTA / SDR | 感觉皮层稀疏放电 + 侧抑制 WTA 竞争 | 机制级 |
| M2 预测编码层级 | 生成-识别闭环 + 误差上传 | 皮层层级预测编码（Rao & Ballard；Friston 自由能） | 机制级 |
| M3 时序关联核 | 突触迹 STDP（+ BCM 元可塑性、稳态缩放） | STDP（Bi & Poo 1998）+ 稳态突触缩放 | 机制级 |
| M4a 工作记忆 | 有界槽位 + 门控写入（可选内容寻址） | dlPFC 持续放电 + 基底核门控 | 机制级 |
| M4b 双速率记忆 | 快权重印迹 + 慢权重巩固（可选 SWS/REM 分期） | 海马快速印迹 + 皮层系统巩固（CLS，McClelland 1995） | 机制级 |
| M4b 吸引子检索 | Hopfield 式模式补全 | 海马 CA3 自动联想吸引子 | 机制级 |
| M5 神经调制 | surprise z 门控 → 四通道 ACh/NE/DA/5-HT | 蓝斑 NE / VTA DA / 基底前脑 ACh / 中缝核 5-HT | 机制级 |
| M6 读出 | 群体读出 + softmax 感知器（局部梯度 p − t） | 皮层→输出的多级中继与群体编码 | 机制级 |
| M7 组合编码 | STDP 链词汇绑定 + 统计分词涌现 | 视觉词形区（VWFA）组合调谐 | 机制级 |
| M8 情景缓冲 | 逐模式寻址 + 链式回放 | 海马情景记忆 + Baddeley 情景缓冲 | 机制级 |
| M9 语义图 | 三元组组合绑定 | 语义记忆网络 + 扩散激活 | 功能级 |
| M10 分层摘要 | 多时间尺度摘要槽 | "细节易逝、要旨长存"的记忆梯度 | 功能级 |
| M11 生成解码 | WM 锚定 + 温度采样 | 内言语与运动皮层生成通路 | 功能级 |
| M12 联想链推理 | 检索→回填→再检索 | 扩散激活式联想推理 | 机制级 |
| M13 上下文漂移 | TCM/CMR 串行回忆 + DG 模式分离 | 海马时间上下文 + 齿状回模式分离 | 机制级 |

### 表 B：稀疏性逐项对照 —— 一处明确欠账

稀疏是本架构的核心组织原则（"稀疏即效率"），因此必须逐项交代清楚：

| 部件 | 当前稀疏性 | 脑对应 | 状态 |
|---|---|---|---|
| M1 编码输出 | **k-WTA 稀疏**（k/N 激活） | 皮层 1–5% 稀疏发放 | ✅ 成立 |
| M2 主干（CSR） | **连接率 12.5%** | dense representation + sparse connectivity | ✅ 成立 |
| M3 STDP | **连接率 1.56%** | 稀疏拓扑突触迹 | ✅ 成立 |
| M4b 大容量表 | **事件驱动稀疏**（只触碰已生长条目） | 海马稀疏索引 | ✅ 成立 |
| **M6 读出** | **100% 稠密** | 人脑连接率 **2e-8**，每神经元约 **1744** 条突触 | ❌ **明确的架构欠账** |

**结论（必须直说）**：**M6 读出目前 100% 稠密，这是明确的架构欠账。** 它既是性能债
（访存受限），也是同构债（与人脑连接率差 4 个数量级）。**幂律稀疏化方案已设计、未实施**
（方案与性能杠杆见《并行与加速架构分析》与 BUGS.md「结构性教训汇总」开放项）。

### 表 C：实现级差异层（不可称"相同"的量化理由）

| 维度 | 人脑 | PHD-Net | 状态 |
|---|---|---|---|

### 结论表述（建议引用原文）

> **PHD-Net 与人脑的关系是"机制级同构的功能性缩比模型"，不是"与人脑架构相同"。**
> 它复制的是大脑的**信息处理原则**（稀疏、局部、事件驱动、双速率、预测、联想），而非大脑的
> **物理实现**。当前最大的同构缺口是 **M6 读出的稠密性**。
