## 一、结论摘要

| 问题 | 结论 |
|---|---|
| 与 Transformer 的差距是「调优」问题还是「结构」问题？ | **结构问题。** 无自注意力（铁律①）+ 无梯度 + 逐 token 无 batch 维三条同时成立，没有任何调参路径能同时补齐 |
| 最根本的差异是哪一条？ | **逐 token 语义**。状态跨 token/shard/epoch 连续演化、读出 W 每步原地更新（P195 master 模式下更新同样逐步落 fp32 master）→ 训练样本无法批处理。P194 的 `micro_batch` 是唯一例外且只作用于读出末端梯度，主干仍逐 token |
| 长程依赖靠什么承载？ | 不是注意力，而是**稀疏 CSR 预测编码（M2/M3）+ 大容量事件驱动稀疏表（M4b，海马体式内容寻址索引）**。载体是**状态与突触**，不是 QKV |
| 与 MoE 的关系 | 只有「稀疏」相似，路由性质相反：MoE gating 学出来；PHD-Net 的 k-WTA 与 CSR conn_k 是发育期随机 + 稀疏先验固定，**路由不学习**。幂律分配（P124）是朝「使用频率倾斜」迈出的一步，但默认关闭且词频是代理值 |
| 能否对标前沿大模型的通用语言能力？ | **不能。** 1B 档 PPL 高的根因是**词表 × 曝光**（P198 诊断）；把容量放大到 30B 只放大容量，不自动产生能力（§五） |
| 与人脑是「相同」还是「同构」？ | **机制同构，不是结构相同。** 六机制均有实现与门禁验证（§三、§四），规模差约 5 个数量级 |
| 速度提升是免费的吗？ | **不是。** 低精度读出会丢弃感知器 `p−t` 的非目标行更新（P110：fp32 99.95% / fp16 26.67% / bf16 5.79%）；P195 主权重模式解除了它（更新落 fp32 master，本机 A/B PPL 2.84→2.15），代价是多一份 fp32 master + ≤N 步 staleness |
| 记忆 / 会话学习 / 生成，现在各到什么程度？ | **记忆 ✓**（事件驱动表真实生长、逐位门禁）；**会话中学习 ✓**（P197：印迹触发 0.67%→~100%，cc_traces 3K token PPL 2474→1308）；**正常生成 ✗**（bigram 合法率 24–35%，需 ≥10⁸ token 曝光） |

## 二、与 Transformer 的结构性差异

不是「我们更省」，而是**五个不可互换的结构选择**。第一条是根，其余是它的推论。

### 2.1 根差异：逐 token 语义 ⇒ 无 batch 维

`PHDNet.step()` 是单时间步接口（`phdnet/model.py`）。WM 槽位强度、STDP 突触迹、LTM 突触、
调制器统计量、`step_count`、**读出 W** 全部跨 token 连续演化，且读出 W 每步原地更新。
评估路径用 `readonly=True` 冻结所有持久状态。

**后果**：Transformer 的训练吞吐来自「序列维并行 + 一次前向算一整批」；PHD-Net 每步的
可并行工作量是一个 token 的触碰量。**这不是实现缺陷，是语义的必然代价。**
P194 `micro_batch` 的定位必须说清：它是**读出末端的梯度时间整合**（等效 n 个串行在线步 × η
的梯度和），不是 Transformer 式的批处理——主干/记忆仍按 token 严格保序。

### 2.2 无梯度：学习规则是局部的、在线的

源码中不存在任何 `backward`/`requires_grad`/`torch.optim` 路径。可塑性只有三种，全部**局部**：

| 机制 | 规则 | 出处 |
|---|---|---|
| M6 读出（softmax 感知器） | `ΔW = −η·(p−t)⊗h`，nll = −log p(correct) | `readout.py` |
| M3 STDP | 三因子时序规则：`Δw ∝ η_eff·f(Δt)`，`η_eff = mod_scale × ne_gain × (发育/临界期项)` | `plasticity.py`、`model.py` |
| M2 / M1 | 误差驱动 ΔW_dn + Oja ΔW_up（1B 档经发育窗口后冻结；eta_oja=0 是 P198 发散防线） | `sparse_pc.py`、`config_1b.py` |

读出的 `p−t` 是**感知器局部误差**，不是链式法则的梯度——误差**不反传主干**（监督信号仅在
末端）。但 P197 的**误差广播**改变了「监督信号只能到读出头」的旧格局：读出 NLL 经 Welford
z 标准化门控本步**主干**学习率（`task_modulation`）并接管 WM 写入 / LTM 印迹判据
（`error_gated_memory`）——误差以**调制**而非**梯度**的方式到达主干，这正是神经调制通路
（neuromodulation）在机器上的对应物。M3 的第三因子 `ne_gain` 来自 M5（multi_modulation 时），
构成完整的三因子结构。

**与 Transformer 的量级差异**：Transformer 的一切能力建立在「可微 + 反向传播 + 大规模梯度
优化」上；PHD-Net 这条链从设计上不存在。训练效率上的差距是**结构性的**，不是学习率、
batch size 或优化器能解决的（§六.2）。

### 2.3 五个维度对照

| 维度 | Transformer | PHD-Net | 性质 |
|---|---|---|---|
| **Token 混合** | 自注意力：每 token 与全序列交互（Vaswani et al. 2017） | **无自注意力**。混合走 M2 层级预测编码 + M3 侧向 + M4a 漏整合 | 铁律①，不可补齐 |
| **长程依赖载体** | QKV 矩阵的内容寻址加权求和 | **稀疏 CSR 预测编码 + 大容量事件驱动稀疏表**（1b 档 2²⁴×72 = 1,207,959,552 突触容量） | 载体不同，非程度差异 |
| **顺序信息** | 位置编码 / RoPE | **无位置编码**。顺序由**状态**（WM / STDP 迹 / LTM 印迹 / 新颖性表）承载 | 铁律① |
| **深度** | N 层堆叠，逐层精炼 | **无堆叠层**。深度 = 状态演化的时间轴 | 铁律① |
| **计算粒度** | 可批处理（序列维并行） | **逐 token 状态演化** → 无 batch 维（micro_batch 仅读出梯度） | 铁律③ |
| **稀疏发生在哪** | 稠密注意力 +（MoE 的）专家路由稀疏 | **突触存在性**稀疏：事件驱动的局部触碰 | 都稀疏，维度不同 |

### 2.4 推论（诚实）

1. **PHD-Net 拿不到 Transformer 的并行红利**。逐 token 串行 + 每步可并行工作量小。
   M2 融合核的配置性单核问题已由 `plain` 消除（P113 服务器实测 M2_infer 5.41×），
   剩下的核用不满全是**架构性**的（论证见《并行与加速架构分析》）。
2. **PHD-Net 也不该拿 Transformer 的评价标准**。在 MMLU 一类 benchmark 上比较一个
   无注意力、无位置编码、逐 token 的**词级联想续写器**是不公平比较。公平维度是：
   **单步触碰量、在线学习能力、状态容量、无灾难性遗忘**。
3. **注意力与 PHD-Net 对应物的关系是「功能替代」而非「同类」**。自注意力是内容寻址的
   全局加权求和；PHD-Net 的大空间表是内容寻址的**稀疏联想存储**——只有已生长的突触参与，
   计算量正比于活跃神经元数而与总容量无关。一个是全连接加权，一个是稀疏索引查找。

## 三、机制完整性评估（哪些脑机制有对应实现 + 验证）

> 判级：**✅ 已验证** = 有实现 + 有专项门禁/实测数字；**◐ 已实现未充分实测** = 有实现 +
> 零崩溃自检，无生产实测结论；**○ 已实现默认关** = 有实现、默认关闭、开启前需 A/B。

### 3.1 与大脑的逐机制对照

| 脑机制 | PHD-Net 实现 | 判级 | 验证 / 实测 |
|---|---|---|---|
| 皮层稀疏编码 + 侧抑制（Olshausen & Field 1997） | M1 k-WTA（`argpartition` 竞争） | ✅ | 12.5% 激活率（1b 档）；全部门禁回归覆盖 |
| 皮层预测编码层级（Rao & Ballard 1999） | M2 SparsePCStack：上行识别 + 下行生成 + 误差迭代 | ✅ | `gate_m2_infer_kernels`（三态对拍）、`gate_m2_learn_fused`；P198 发育窗口实测 PPL 3403→389 |
| dense representation + sparse connectivity（皮层连接率 ~10⁻⁵~10%） | M2/M6 CSR 结构性稀疏（稠密栈已删，稀疏是唯一形态） | ✅ | `gate_parallel_consistency`（k=n_in 时与稠密数值一致）；M2 12.5% / M6 4.2% 连接率 |
| STDP 时序可塑性（Markram 1997 / Bi & Poo 1998） | M3 稀疏拓扑 + 突触迹（pre/post 顺序约束） | ✅ | `gate_stdp_parity`（numba/numpy 对拍）；η 缩放语义已修正（P192，`gate_ltm_trace_semantics` 32/32 覆盖迹语义） |
| 海马模式分离（pattern separation） | P197 SDR 支撑集新颖性检测（顺序无关哈希 + LRU 熟悉化） | ✅ | `gate_insession_learning` A 组；印迹触发率 0.67%→~100% |
| 海马快印迹（one-shot episodic memory） | M4b 事件驱动印迹（相邻模式配对，"fire together, wire together"） | ✅ | `gate_ltm_csr_equivalence` / `gate_ltm_kernels`（recall 全链路逐位）/ `gate_ltm_learn_batch` |
| 突触结构可塑性（经验依赖生长） | M4b OnlineCSRTable：LTP 驱动生长、LTD 只作用已存在突触、2× 扩容、上限 m_out | ✅ | `[big-ltm]` 实时利用率行；cc_traces 3K token LTM 生长 +81% |
| 记忆巩固（海马→皮层 / 睡眠） | `sleep()` consolidate；`staged_sleep`（SWS downscale + REM 回放）；`plateau_sleep`（验证 PPL 平台期触发，默认开） | ◐ | 巩固路径有门禁；**诚实边界**：容量表上无快/慢权重分离，退化为乘性衰减；int8 量化台阶下 1% 衰减零效果（需 forget≳3） |
| 灾难性遗忘的回放对策（replay） | `readout_replay`：储备旧 (输入,目标)，当前表征下重训读出 | ✅（默认开） | P197 门禁 C 组（单对记忆 nll 降 >50% 且不泛化）；长期曲线未测 |
| PFC 工作记忆（持续放电 + 基底核门控，Miller & Cohen 2001） | M4a：4 槽位漏衰减 + 门控写入 + 最弱槽位选择 | ✅ | `gate_wm_modulator`；P197 起写入门由任务误差驱动 |
| 神经调制：NE/ACh/DA/5-HT（Hasselmo、Yu & Dayan） | M5 单通道（surprise→gate）+ 四通道版（`multi_modulation`）；T1.1 任务误差调制 | ◐ / ○ | 单通道 + 任务门默认开（P197 门禁 D 组）；四通道默认关，无生产实测 |
| 发育临界期（可塑性窗口关闭） | `pc_dev_steps` 余弦退火窗口（P194 Q2）；`critical_period`（默认关） | ✅ | 1b 档 20000 步窗口；P198 实测 40K token PPL 3403→389（bigram 78%） |
| 稳态（homeostasis，Turrigiano） | PC 稳态缩放（1b 档开）、STDP 稳态（默认关）、逐神经元目标发放率（默认关） | ◐ / ○ | PC 侧随全部门禁回归；STDP/逐神经元侧零崩溃自检 |
| 突触巩固/修剪的幂律倾斜（use it or lose it） | M6 幂律异质连接（`sparse_alloc`，k_i ∝ counts^alpha，预算硬约束） | ○ | `gate_readout_powlaw`（32 例，alpha=0 逐位等价）；**默认关**——词频是代理值（1/rank），词表字典序非频次序，方向可能反；加速器对非均匀行宽 fail-fast |
| E/I 抑制平衡（皮层 ~80/20） | `ei_synapses`（抑制出边负权重）+ `lognormal_init` 重尾初始化（Song et al. 2005） | ○ | 零崩溃自检；无生产实测 |
| 内言语受情景流约束 | `episodic_len` 情景缓冲接入生成（默认关） | ○ | 无独立实测 |

**总体**：✅ 已验证 10 项、◐ 已实现未充分实测 3 项、○ 已实现默认关 4 项（混合项按两半计）。
**没有「无对应实现」的脑机制条目**——差距在「默认关/未实测」，不在「没做」。

### 3.2 与传统 ANN 的差异定位

| 维度 | 传统 ANN（MLP/CNN/RNN） | PHD-Net |
|---|---|---|
| 学习信号 | 反向传播（全局误差 + 链式法则） | 局部三因子（误差/调制/时序），无链式法则 |
| 权重存在性 | 全连接或人工剪枝（剪完不再长） | 突触**随经验生长**（事件驱动，LTP 驱动） |
| 记忆 | 权重（静态）+ 隐状态（RNN） | 三级：WM 槽位（秒级）/ STDP 迹（亚秒）/ 大空间表（持续生长）+ 新颖性表 |
| 可塑性调控 | 学习率调度（全局、外生） | 神经调制（surprise/任务误差驱动，每 token 在线） |
| 时间 | 展开的时间步（BPTT）或无时间 | 状态连续演化，无展开、无位置编码 |
| 稀疏 | 通常稠密 | 结构性（不存在的突触不存储不计算）+ 激活稀疏（k-WTA） |

## 四、与 MoE 的关系：只有「稀疏」相似

MoE 的稀疏是**学出来的路由**，PHD-Net 的稀疏是**长在结构上的先验**。这个差别决定两者的
能力上界，比「谁更省算力」重要得多。

| 维度 | MoE（Shazeer et al. 2017） | PHD-Net |
|---|---|---|
| **稀疏位置** | 每 token 激活 top-k 专家（神经元块） | 每 token 激活 k 个编码单元（M1）/ 触碰存在的突触（M2/M3/M6） |
| **路由是否学习** | **是**。gating 网络随主损失训练 | **否**。`_random_csr` 建图时随机采样并固定 |
| **稀疏度由谁定** | 学习 + 容量因子/负载均衡损失 | 结构先验：`k_sparse = w//8`、`conn_k = w//8`、`m_lateral = 16` |
| **训练信号** | 全局损失反传（需梯度） | 局部感知器 `p−t` + STDP 三因子（无梯度） |
| **容量不均** | auxiliary loss 矫正 | 幂律分配已接入（P124）但**默认关**且词频是代理值 → 天然不均仍未实际处理 |

**1b 档实测稀疏口径**（`build_cfg("1b")` 实算，非估算）：

| 机制 | 口径 | 值 | 类型 |
|---|---|---|---|
| M1 k-WTA 输出 | 128 / 1024 | **12.5%** | 激活稀疏 |
| M2 CSR 连接 | 128 / 1024 | **12.5%** | 连接稀疏 |
| M3 STDP 出边 | 16 / 1024 | **1.56%** | 连接稀疏 |
| M6 读出（生产 CLI） | 128 / 3072 | **4.2%** | 连接稀疏（库默认稠密 0；两者不一致是事实） |

**结构先验的代价（诚实）**：免训练路由（无训练预算、无负载均衡损失、无专家坍缩），
但**失去自适应**——分布偏移时均匀 k-conn 不自适应，MoE 的 gating 会。这是「结构稳定性」
与「分布适应性」的取舍，不是缺陷也不是免费收益。

## 五、规模外推：方法与不确定性

**明确声明：PHD-Net 没有实测 PPL-规模曲线。** 本节给方法与瓶颈分析，不给承诺。

### 5.1 四档预设与容量实算（`capacity_report`，V=51,962，readout_conn_k=128）

| 项 | `smoke` | `1b` | `1b_max` | `30b` |
|---|---|---|---|---|
| width | 256 | **1024** | 4096 | 1024 |
| big_ltm_N × m | 2²⁰×60 | **2²⁴×72** | 2²⁴×60 | **2²⁹×56** |
| 固定突触小计 | 6,819,328 | **9,289,984** | 48,663,808 | 9,289,984 |
| **总容量 ≈ ×10⁹** | 0.0697 | **1.2172** | 1.0553 | **30.0741** |
| M4b 占比 | 90.2% | 99.2% | 95.4% | 99.97% |

> 口径注：稠密读出（conn_k=0）同词表为 **1.3702e9**；满词表 73,958 为 1.2201e9。
> 引用必须带 `readout_conn_k` 与词表口径。更早的 1.317e9（big_ltm_m=60 时代）已作废。

### 5.2 哪些量线性增长、哪些会变成瓶颈

| 部件 | 增长行为 | 瓶颈性质 |
|---|---|---|
| **M4b 大空间表** | 容量线性增长；每步计算量只正比于活跃神经元数 | 随机访问 → 访存受限；索引映射本身 17.2 GB（30b）；稀疏存储前提是 `csr_online` |
| **M6 读出** | GEMV：矩阵规模 V×hidden 线性增长，每步只传一个 h | 带宽受限；加速器迁移不改变本质（4.2% 连接率省 8× 流量） |
| **M2 CSR 主干** | 计算量线性增长；`plain` 已消除配置性单核 | 并行度受限已缓解；剩余核用不满是架构性 |
| **M3 STDP** | m_lateral 固定 → 不随 width 增长 | 不是瓶颈；只走 numba CPU（迁移丢逐突触状态） |
| **M4b 生长** | — | 无法上加速器（定长行 + 预留槽 + 生长是 CPU 结构操作） |

### 5.3 外推的不确定性（必须一起写）

- **没有跨档位 PPL 曲线**。1b/1b_max/30b 没有可比 PPL 实测，「容量→能力」关系尚未建立。
  任何「30B 档能达到 X」都是编造。
- **已知的历史事实是反方向的**：固定数据预算下放大参数，PPL 反而变差（欠训练效应）。
  P198 的词表预算诊断给出了同一现象的另一面：**目标空间（词表）与曝光（tokens/vocab）
  必须同步增长**——这与 Transformer 侧缩放律（Kaplan 2020 / Hoffmann 2022）的前提
  「参数、数据、计算同步增长」同构，但 PHD-Net 目前只具备容量一项。
- **稀疏度不随规模变化**：连接率恒定 12.5%，放大 width 只线性放大固定突触；
  M4b 占 99%+ 的容量放大时稀疏度不变——「更大」和「更稀疏」不是同一件事。
- **每突触效率未知**：M4b 容量是随机生长的，利用率随训练增长的实测曲线尚不存在。

## 六、欠账与诚实边界

### 6.1 能力边界三态（当前最诚实的一行）

| 能力 | 状态 | 证据 |
|---|---|---|
| **记忆（大容量存储）** | **✓ 已达** | 事件驱动表真实生长、逐位门禁、`[big-ltm]` 利用率实时口径；检索路径 numba 化（44.6×/21.9×）后无计时盲区 |
| **会话中学习** | **✓ 已达（机制层）** | P197：新颖性驱动印迹 0.67%→~100%；误差广播把任务误差送到主干门控；回放/平台期睡眠默认开；cc_traces 3K token PPL 2474→1308、LTM 生长 +81% |
| **正常对话生成** | **✗ 未达** | 1B 档 bigram 合法率 24–35%；P198 截断（top-k/nucleus）解决的是「可读性下限」不是「质量上限」；接近正常需 ≥10⁸ token 曝光——**机制在、数据预算不在** |

### 6.2 无梯度 → 训练效率差距是结构性的

PHD-Net 不存在反向传播路径（§二.2）。与 Transformer 的差距不由参数量、学习率或优化器决定，
而由「是否可微」这一前提决定。**「训练效率追赶 Transformer」不是可执行的工程目标**，
除非放弃铁律②——而那会取消整个脑同构框架。P194–P197 的取向是把**局部规则的学习效率**
（发育窗口、误差广播、回放、主权重）推到局部框架内的上限，而不是引入梯度。

### 6.3 逐 token 语义的并行代价

进程用核数仍 ~1/191（NPU 99%）：配置性原因（M2 单核）已被 P113 消除，
剩余全是架构性——CPU 侧总量小、访存带宽饱和区抬不高核占用率。
结论：**「191 核用不满」是逐 token 语义的必然代价，不是「还有优化没做」。**

### 6.4 精度语义代价（P110 → P195 的完整链条）

- P110 实测：低精度把感知器 `p−t` 的非目标行更新舍入丢弃（fp32 99.95% / fp16 26.67% /
  bf16 5.79%，目标行均 100%）→ 「只提升目标行」退化为纯 Hebbian。
- P194 Q4：默认回到 **fp32**（精确语义优先于带宽）。
- P195：**主权重模式**（fp32 master + 低精度影子）在**保留访存收益的同时解除舍入丢失**
  （本机 A/B：fp8 无 master 2.84 → fp8+master 2.15，fp32 基线 2.14；两臂一致）。
- 剩余代价：+866.7 MiB fp32（1b 档）、≤8 步影子 staleness、torch.compile 禁用、
  NPU Graph 重量化移出图外。默认 off（不知情的人不该被动多付一倍内存）。

### 6.5 评测与数据口径的缺口

- **历史 PPL 锚点不可比**：P192（STDP η 缩放修正）与 P193（LTD 迹补偿）都是学习规则
  语义变更；旧锚点 394.4687/359.2603 只存 git 历史，须重测后才能引用。
- **中文能力未经检验**：远程分片实测 en 50% / unk 47%（实为代码）/ zh 仅 2%，
  与早期「中文 95%」记录直接矛盾（数据制备问题，非训练代码问题）；
  评测基线恰是中文维基语料——评测口径与训练语料不匹配的问题仍在。
- **P198 验证口径是缩小词表的**（3,392 词表 / 40K token，PPL 3403→389、bigram 78%）——
  它证明的是发育窗口机制有效，**不可外推为 1B 档 51,962 词表的预期**。

### 6.6 其余开放项

| 项 | 性质 | 状态 |
|---|---|---|
| 幂律读出的真实词频 | 设计缺口 | 构造期拿不到语料词频；两阶段方案（先跑再重建读出）未实现（会改 ckpt 结构） |
| 会话学习的长期曲线 | 评测缺口 | P197 门禁是短程判据；跨会话保持（数百万 token）未测 |
| 多数机制默认关闭 | 工程现实 | §三 的 ○ 级条目只有零崩溃自检，无生产实测结论 |
| 无跨档位 PPL 曲线 | 方法论缺口 | §五.3 |
| 缺可比 benchmark | 评价缺口 | 与前沿模型无法在同一张能力表上比较；本文不做能力排名 |
| M3/M4b 无法上加速器 | 平台硬约束 | 逐突触状态 / 结构生长不可设备化 |
| CI 远端状态 | 工程债 | 两套 workflow，未核验，不宣称全绿 |

### 6.7 不做的事

本文**不**给「预计 N 年追上 X」式预测；**不**给无平台的加速倍数（x86 与昇腾常常方向相反）；
**不**引用不可比的旧 PPL 锚点；**不**把「大脑稀疏度 = 1–5%」或「人脑 86.1×10⁹ 神经元」
当无争议定论使用；**不**声称 PHD-Net 在任何能力维度上与 Transformer 可比。
