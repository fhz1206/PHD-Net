## 一、结论先行

| 问题 | 一句话结论 |
|---|---|
| 通用语言能力能否对标 GLM-5.3-Flash？ | **不能，且差距不由参数容量决定**——差距来自经验量（10⁸×）与表示学习机制；100B 只会放大容量，不会自动转化为能力（证据见 §2.5 三情景） |
| 100B PHD-Net 的胜场在哪？ | **单步计算量少 4–6 个数量级、本机 CPU 可跑、在线单样本、无灾难性遗忘**——这四项与规模无关，是结构性差异 |
| 100B 会不会反而变差？ | 会：**容量单向扩容已被实测证伪**（M4：接入 1B 容量后 PPL 102.11 vs 稠密 89.88，且慢 5.7×）；扩容必须同时解决"谁来用这些突触" |
| 最关键的一条结论 | PHD-Net 不缺算力预算，**缺的是能把容量转成能力的可塑机制**——M9 五项表示层改进全部为负，这是当前架构的真正瓶颈 |
| 与人脑架构是否相同？ | **不能称"相同"，可称"机制同构"**——12/12 模块有明确神经认知对应，5 项差异维度已统一；但规模差 4–5 个数量级 |

**诚实前提**：本文的"竞争力"均在**本机 CPU 资源受限**与**窄任务**前提下成立；100B 外推是**假设驱动的情景推演**，PHD-Net 目前**没有实测缩放曲线**，任何外推的不确定度都在数量级水平。

## 二、PHD-Net 100B vs GLM-5.3-Flash（320B-A18B MoE）

### 2.1 先解决口径：这两种"参数"不能直接比大小

两者说的"参数"是不同物理量，直接比 100B vs 320B 没有意义。必须拆成三种记账口径：

| 口径 | 含义 | GLM-5.3-Flash | PHD-Net 100B |
|---|---|---|---|
| **存储参数**（权重文件里存了多少数） | 需要持久化的数值总量 | 320B（FP8 ≈ 306 GiB / BF16 ≈ 640 GB） | 100B 突触槽（但实际只存**已生长**的条目） |
| **激活参数 / 每步触碰量**（处理一个 token 要动多少个数） | 单步实际计算规模 | 18B（288 路由专家 + 1 共享，top-8 激活 ≈ 5.6% 专家 + 稠密注意力部分） | ≈ 5×10⁴ 突触/步（推算，见 2.4） |
| **稠密可训练参数**（端到端接收训练信号） | 参与优化的参数 | 320B 全部可训（反向传播） | LM 栈 **≈0.2M**（M5 配置 1.24M）；100B 突触只有被触碰的才更新 |

**这张表已经说明了一半的结论**：GLM 用 320B 存储换取每 token 18B 的激活计算；PHD-Net 用 100B 容量换取每步 ~10⁴–10⁵ 的事件触碰。**两边都在做稀疏化，只是稀疏的维度不同**——GLM 稀疏在"专家路由"，PHD-Net 稀疏在"事件驱动的局部突触"。

### 2.2 对标对象事实卡：GLM-5.3-Flash（引用，2026-08-26 发布）

| 项 | 数值 | 性质 |
|---|---|---|
| 架构 | MoE；总参数 **320B** / 激活 **18B**；语言 45 层（GLM-4.5 为 92 层） | 引用 |
| 专家 | 288 路由专家 + 1 共享专家，**top-8** 激活 | 引用 |
| 注意力 | KDA 线性注意力 + NoPE 稀疏 MLA 混合，支持 MTP；注意力计算约 3× 更少、KV cache 4.4× 更小 | 引用 |
| 上下文 | 1,048,576 token（1M），最大输出 128K | 引用 |
| 模态 | 原生文本 / 图像 / 视频（448px 视觉编码器，视觉侧 24 层） | 引用 |
| 预训练 | **30T token** 多模态语料；原生 FP8（另有 BF16 变体） | 引用 |
| 权重体积 | FP8 ≈ 305.8 GiB；INT4 量化可在单张 24 GB 卡上跑 | 引用 |

### 2.3 PHD-Net "100B" 的三种定义（必须明确，否则外推无意义）

| 版本 | 结构 | 稠密可训练参数 | 说明 |
|---|---|---|---|
| **A 容量版** | 事件驱动突触表扩到 100B 槽（如 N≈2³⁰ 神经元 × m≈93 出边），**LM 栈保持当前规模**（n_top=128） | ~0.2M | 只扩书架不扩读者；**已被 M4 实测判定为无效路径** |
| **B 同比例放大版** | 容量 100B + LM 栈同比放大（n_top 128→4096、n_sdr→1024），靠 T5.1-lite 稀疏 PC 压住 O(n²) | ~20M | 需要可贵的大量 same-scale 经验填充才有意义 |
| **C 完整版** | B + 经验填充到 10⁸–10⁹ token + T3.2 常态检索融合 + M1–M13 全模块 | ~20M + 100B 容量 | 乐观情景的前提；本机不可达，需集群 |

### 2.4 资源与效率维度（推算）

**每步触碰量**（版本 A/B 相同，取决于 SDR 活跃位与每维哈希索引数）：
- 每步线索 = n_top(128) × k_hash(4) ≈ **512 个源索引**；每源出边 m≈93 → **≈4.8×10⁴ 条边/步**；
- predict + learn 两遍 → **≈10⁵ 次乘加/步**，即 **~2×10⁵ FLOPs/token**（量级估算，±1 个数量级）；
- 对照 GLM-5.3-Flash：18B 激活 × 2 ≈ **3.6×10¹⁰ FLOPs/token**。

> **差距：约 5 个数量级**（保守区间 4–6）。这是 PHD-Net 唯一不依赖任何假设就能成立的结构性优势。

| 维度 | PHD-Net 100B（推算） | GLM-5.3-Flash（引用/推算） | 判定 |
|---|---|---|---|
| 存储 foot print | **已生长条目数决定**：ints8 + CSR 后 ~8–13 B/突触；Python dict 路由每条实际 ~100+ B → 真上 100B **必须迁移到 CSR/扁平数组**（1B 档在线 CSR 已迁移落地：91.8 → 16.0 B/条目、5.74×↓、落盘恢复逐位一致——O3；100B 规模客观受限） | FP8 306 GiB 常驻；INT4 ≈ 164 GB | PHD-Net 优（1B 档 CSR 已落地；100B 规模客观受限，见 §六 工程债） |
| 单步延迟 | 事件驱动 O(1) 哈希，**与容量解耦**：实测 1B=1.28 ms/步、2.01B=0.93 ms/步 → 100B 应在 **同一量级（~1 ms）** | 每 token 需读 18B 激活权重：18 GB ÷ ~3 TB/s HBM ≥ **6 ms**（带宽下限，实际含注意力更高） | **PHD-Net 优 1 个数量级**（CPU vs GPU 集群） |
| 训练算力 | ∝ 经验 token 数 × ~2×10⁵ FLOPs：训 10⁹ token ≈ **2×10¹⁴ FLOPs** | 6 × 18B × 30T ≈ **3.2×10²⁴ FLOPs** | **PHD-Net 优 10 个数量级**（但不在同一能力点） |
| 训练数据量 | 当前冻结内部语料 23,504 字符；假定 C 版填 10⁹ token（`datasets/pretrain/` = Infinity-Instruct 7M_core，2026-09-22 拍板并已就位（7,449,106 条 / 10.07 GB 文本）） | 30T token | 差 4–8 个数量级 |
| 上下文 | WM 有界槽（4–8）+ 情景缓冲串行链；**无位置编码**，长程依赖靠联想链 | 1M token 窗口内直接访问 | **GLM 优**（结构性劣势，见 §四 B4） |
| 硬件门槛 | 本机 CPU / 12.6 GB 内存可跑 | FP8 多卡集群；最低部署亦需 8×H20 或 2×A100-80G | **PHD-Net 优多个数量级** |
| 在线持续学习 | 天然支持，**BWT +0.000 实测** | 无原生在线学习；微调伴随灾难性遗忘（对照 −1.000） | **PHD-Net 独占** |
| 单样本记忆 | 一次印迹，30% 噪声线索下 **100% 实测** | 仅 in-context（受窗口长度约束） | **PHD-Net 独占** |
| 多模态 | 无（单通道符号输入） | 原生文本/图像/视频 | **GLM 独占** |

### 2.5 能力维度：三情景外推（**估算**，非实测）

**必须先承认的方法学事实**：PHD-Net 目前只有**两个数据点**（0.2M 稠密 LM 栈、1B 突触容量），**没有 scaling curve**。因此以下不是预测，而是"如果满足这些条件，大致落在哪个区间"的情景推演。

推算基线：当前系统（默认 256 维栈）在**冻结语料 `eval_corpus/internal_corpus.txt`（23,504 字符）**上的字符归一 PPL = **78.16**（bpc 6.288），
同语料 Transformer 参照为 85.27（0.52M）；狭义 Transformer 参照 loss scaling 的经验指数 α≈0.34（Chinchilla 量级，**借用于 Transformer，未对 PHD-Net 验证**）。

| 情景 | 配置 | 关键假设 | 字符归一 PPL（区间） | 对应地位 |
|---|---|---|---|---|
| **悲观（证据最强）** | 版本 A：单独把容量堆到 100B | M4 实测的类比：容量扩容不产生 PPL 收益（102.11 vs 89.88，且慢 5.7×） | **100–120**（≈ 无改善） | 连"第十万分之一 GLM"都谈不上；仅得到一个巨大的空书架 |
| **中性** | 版本 B：容量 + LM 栈同比放大到 ~20M + 经验填到 10⁸ token + T3.4 内容寻址 / ② 回放稳定读出 | 表示层保持冻结（η_pc=0），T3.4 的 −1.6% / ② 的 −1.4% 可复现（泛化探针近域 −1.8~−2.2% 再证）；按 Transformer α 折半兑付 | **20–60** | 约等于"0.1–1M 参数稠密 Transformer 在同语料"的水平；**仍比 GLM-5.3-Flash 低数个数量级的能力层级** |
| **乐观** | 版本 C + **必须先打破"冻结表征"约束** | 需要先把 M9 五项失败的表示层机制（V4'/①/①+T1.2/T2.2/③）之一做成正收益 | **10–20** | 接近现代 LLM 在小领域语料上的水平；**但这是当前的已知卡点，不是推演结果** |

**这条表格最重要的一列是"关键假设"**：
把 100B 变成能力的不是容量，而是三个尚未兑现的前提——
1. **经验填充**：100B 突触按当前每 step ~10⁵ 触碰量，填满需要 ≈10⁶ 步以上连续学习（当前全部实验只在 10³ 步量级）；
2. **表示层可塑性**：M9 证明五项表示层改进全部为负（冻结语料 +18.4%～+62.9%），"冻结表征"是多轮一致结论；不开这个锁，容量只能当索引表用；
3. **检索/融合规模化**：~~T3.2 是当前唯一稳定的正增益~~ **已证伪（2026-09-21）**——T3.2 四轮增益 −2.4% → −0.65% → −1.1% → **+3.2%（有害）**，符号翻转证伪其稳定性；当前稳定正增益为 T3.4 内容寻址（−1.6%）与 ② 回放稳定读出（−1.4%），其在 100B 容量下能否兑现**完全未被验证**。

### 2.6 判定矩阵（哪些维度能赢、哪些必输）

| 维度 | 判定 | 依据 |
|---|---|---|
| 通用语言理解 / 生成 / 指令遵循 | **必输**（不是分数低，是任务形式不可执行——无词级语义接口） | GLM AA 57 / Terminal-Bench 84.3；PHD-Net 在这些基准上记为 0 |
| 长上下文（≥10³ token） | **必输**（结构性） | GLM 1M 窗口；PHD-Net 靠 WM 槽 + 串行联想链 |
| 每 token 计算效率 | **赢 4–6 个数量级** | 2×10⁵ vs 3.6×10¹⁰ FLOPs/token |
| 训练算力成本 | **赢 ~10 个数量级** | 成本 ∝ 经验量而非容量 |
| 部署门槛 / 硬件可得性 | **赢**（CPU 可跑 vs 306 GB 显存多卡） | 实测 1B 容量 RSS 增量 ~0 MB |
| 在线持续学习 / 灾难性遗忘 | **赢（独占）** | BWT +0.000 vs −1.000 |
| 单样本关联记忆 | **赢（独占）** | 实测 100%（30% 噪声线索） |
| 脑机制同构性 | **赢（独占）** | 12/12 模块对应；MoE 路由无生物对应 |
| 多模态 | 必输 | PHD-Net 单通道符号输入 |

**一句话**：> 100B 的 PHD-Net 不会成为 GLM-5.3-Flash 的替代品，而是一个**完全不同生态位**的系统——GLM 卖"能力"，PHD-Net 卖"学习方式与资源效率"。把它放在同一张 benchmark 表上比较，本身就是口径错误。

### 2.7 要让预估可证伪：必须先补的三组实测

1. **PHD-Net 的 scaling curve**：固定经验量（如 10⁶ token），扫 3–4 个容量点（1B / 10B / 100B），看 PPL 是否下降——**这是本文全部外推的唯一证伪手段**（当前拿不到接近 GLM 能力级别的证据）。
2. **锁定 100B 在线结构**：把 dict 邻接表迁移到 numpy CSR/开放寻址（T5.3 已有快照格式），实测 10⁷–10⁸ 突触量级的单步耗时与内存——不解决这条，100B 连工程上都站不住。
3. **寻找正向的表示层可塑性机制**：在受控条件下（小语料、固定步数）逐一测试「更慢的稳态缩放率 + 更强调结构性的生长 + 生成式回放」的组合，把 M9 的五项负结果翻出至少一项正值。

## 三、与市面 LLM 对比：训练与推理两个维度

### 3.1 训练维度

| 维度 | PHD-Net（实测） | 稠密 Transformer 1B（同机推算） | GLM-5.3-Flash（引用） |
|---|---|---|---|
| 训练范式 | 在线单样本、局部规则、无反向传播 | 离线小批量 + 全局梯度（Adam） | 同左 + 大规模集群 |
| 本机可训性 | ✓ 1.92 s / 1500 步 | ✗ 训练态 ≥16 GB > 12.6 GB 物理内存 | ✗ 差 3 个数量级内存 + 无 GPU |
| 训练总计算量 | ~1.5×10⁸ FLOPs（推算自活跃边数） | 6×10⁹ FLOPs/token × 语料长度 | ~3.2×10²⁴ FLOPs（30T token） |
| 训练经验量 | 23,504 字符（冻结内部语料 `eval_corpus/internal_corpus.txt`） | — | 30T token |
| 单步耗时 | 1.28 ms（推理+学习一体） | ~0.12 s/token（算力下限） | 集群摊薄 |
| 持续学习 | 天然具备；**BWT +0.000 vs Transformer −1.000** | 需微调+重放，灾难性遗忘 | 同左 |

**关键机制差异**：PHD-Net 的训练成本与**容量解耦**，与**经验量成正比**；Transformer-MoE 的成本 = 激活参数 × token 量 × 6 FLOPs。

### 3.2 推理维度

| 维度 | PHD-Net（实测） | 1B 稠密 Transformer（推算） |
|---|---|---|
| 单步延迟 | **1.28 ms**（CPU） | 40–200 ms/token（算力下限 39 ms + 带宽 ~160 ms） |
| 内存（推理态） | ~197 MB（含解释器基线） | 4 GB（fp32）/ 2 GB（fp16） |
| 每步有效计算 | 数千条活跃突触 | 10⁹ 参数全量参与 |
| 容量扩展性 | 2.01B 实测 0.93 ms/步（与容量解耦） | 每加 1 参数付全量算力与显存 |
| 产出粒度 | 1 个符号级事件/步 | 1 个语义 token/步 |

**诚实注记**：这不是对等比较。PHD-Net 每步处理一个符号事件且只在窄任务上有产出；延迟优势只在"同类窄任务"内成立。

| 泛化探针（冻结语料训练，`tests/demo_gen.py`） | 近域四文档 inflation **0.68–1.05×**（优，且优于统计基线 20–30%）；远域维基 OOD **9.38×**（不足，OOV 58.5% 覆盖墙，数据规模问题） | T3.4+② 加强组：近域再 −1.8~−2.2%，远域无效（−0.2%） |
| 持续学习 BWT | **+0.000** vs **−1.000** | 无灾难性遗忘 vs 完全遗忘 |
| 长程复制 / 情景记忆（M13，n=4/8/16） | **45.6% / 25.9% / 17.8%** | 随机 8.3% ／ 字符级 LM ~10% |
| 知识三元组检索 | 67%（12 条干扰） | — |
| 2 跳链式推理（未存储事实） | 75% vs 直接查询 0% | "推理独立于存储"的机制证明 |
| 多跳关联（12 步干扰） | 67% vs 无摘要槽 13% | — |
| 生成 bigram 合法率 | 98–99.5%（τ≤0.3） | 随机 1.0% |

**差距根因（按重要性排序）**：
1. **经验规模**：10⁸× 以上的训练数据量差距——这是能力差距的主体；
2. **表示层可塑性受限于"冻结约束"**：M9 五项表示层机制全部为负（+1.9% ~ +59.2%），是当前架构最硬的卡点；
3. **记忆容量未被填充**：1B 利用率仅 0.0003%——容量是"可生长上限"而非"已用能力"。

### 3.4 生态位结论

> PHD-Net **不能替代通用 LLM**。它的价值场景是：资源受限设备上的持续学习、少样本关联记忆、流式数据的事件驱动建模、以及作为 LLM 的**可学习记忆外挂**（LLM 管语言能力，PHD-Net 管在线记忆与适应，互补而非替代）。

## 四、"能打过多少大小的模型"：三个口径

### 口径 1：资源口径（本机 CPU）——打过一切稠密 Transformer
0.5B 以上稠密模型训练态内存（参数+梯度+Adam ≥ 8 GB）即超本机物理上限；1B 稠密推理也需 40–200 ms/token。
**1B PHD-Net：197 MB、1.28 ms/步——本机上唯一"可训练的 1B 容量"形态。**

### 口径 2：能力口径（同语料）——窄任务匹配 0.4–2.2M Transformer
在同一架构设计语料、同一字符归一 PPL 口径下，PHD-Net（89.48）优于 0.44M（103.53）与 2.22M（121.02）Transformer，且无灾难性遗忘 → 判定「更强」。
> **性质标注**：这是**单语料、单指标、窄任务**结论；"0.4–2.2M 级等效"受 M9 证据约束——该量级是在"冻结表征 + 检索融合"组合下取得的，不是 xěchnically 可扩展的参数等效。

### 口径 3：机制口径（**这才是本文真正的结论**）
单样本印迹、在线持续学习、补全式检索、事件驱动容量生长——**任何规模的稠密 Transformer 或 MoE 都原生不具备**。
这不随参数规模消失：GLM-5.3-Flash 再大，也不会在一次前向里把自己的突触改造成长期记忆。

## 五、人脑架构对照：确认"相同"还是"同构"？

**直接回答**：不能确认"与人脑架构相同"；能确认的是**"机制级同构的功能性缩比模型"**（brain-inspired / mechanism-isomorphic）。

### 表 A：机制同构层（12/12 模块；9 项机制级 + 3 项功能级）

| 模块 | PHD-Net 实现 | 大脑对应 | 层级 |
|---|---|---|---|
| M1 稀疏编码 | k-WTA / SDR | 感觉皮层稀疏放电 + 侧抑制 WTA 竞争 | 机制级 |
| M2 预测编码层级 | 生成-识别闭环 + 误差上传 | 皮层层级预测编码（Rao & Ballard；Friston 自由能） | 机制级 |
| M3 时序关联核 | 突触迹 STDP（+ BCM 元可塑性、稳态缩放） | STDP（Bi & Poo 1998）+ 稳态突触缩放 | 机制级 |
| M4a 工作记忆 | 有界槽位 + 门控写入（可选内容寻址） | dlPFC 持续放电 + 基底核门控 | 机制级 |
| M4b 双速率记忆 | 快权重印迹 + 慢权重巩固（可选 SWS/REM 分期） | 海马快速印迹 + 皮层系统巩固（CLS，McClelland 1995） | 机制级 |

| M7 组合编码 | STDP 链词汇绑定 + 统计分词涌现 | 视觉词形区（VWFA）组合调谐 | 机制级 |
| M8 情景缓冲 | 逐模式寻址 + 链式回放 | 海马情景记忆 + Baddeley 情景缓冲 | 机制级 |
| M9 语义图 | 三元组组合绑定 | 语义记忆网络 + 扩散激活 | 功能级 |
| M10 分层摘要 | 多时间尺度摘要槽 | "细节易逝、要旨长存"的记忆梯度 | 功能级 |

| 维度 | 人脑 | PHD-Net v0.0.0 | 状态 |
|---|---|---|---|
| 突触类型 | E/I 分型 + 侧向抑制 | 已统一（`ei_synapses`，默认关） | ✅ 已统一 |

### 结论表述（建议引用原文）
> **PHD-Net 与人脑的关系是"机制级同构的功能性缩比模型"，不是"与人脑架构相同"。** 它复制的是大脑的**信息处理原则**（稀疏、局部、事件驱动、双速率、预测、联想），而非大脑的**物理实现**。
