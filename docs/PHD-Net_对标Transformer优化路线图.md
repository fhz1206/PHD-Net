# PHD-Net 对标 Transformer 优化路线图

> 📌 **现状快照（2026-09-27 整理）**：本文已按「删除过时与历史消息、只保留现状」的原则整理；引用已删除语料/旧基线的历史段落以现状结论为准，当前基线与口径见《性能评估与迭代方案（现状版)》。

> 架构版本：v0.0.0 ｜ 定稿：2026-09-20
> 配套：《架构设计》《性能评估与迭代方案》《竞争力与脑同构性评估》
> **目标**：同等参数规模、同等训练数据量、同等计算预算（下称"三同"）下，PHD-Net 训练出的模型能力达到同规模 Transformer **相当乃至更强**的水平。
> **铁律不变**：无自注意力、无位置编码、无堆叠层；每项改进必须有神经认知机制对应，不引入全局非局部梯度。

**本版是状态摘要，不是实施日志。** M1–M9 已全部收官，五轨道每个条目都有实测结论（含负结果），
因此不再逐条重述"怎么做、中间崩了几次"——每个条目只留**一句话结论 + 是否建议启用**；
实施过程见 §六的证据脚本与 `outputs/*.log`。真正还没做的，集中在 §五「开放项」。

## 一、目标定义与"三同"口径

| 维度 | 对齐口径 | 说明 |
|---|---|---|
| 参数规模 | ① 稠密可训练参数对齐（主口径）；② 内存占用对齐 | PHD-Net 有两个数字：LM 栈稠密参数（≈0.2M）与事件驱动突触容量（1B）；② 作为资源优势单独报告 |
| 训练数据 | 同一语料、同字符数 | 双方各自最优 tokenizer，报告时注明粒度差异 |
| 计算预算 | 同 CPU-hours（本机 8 线程 CPU） | 记录墙钟 + process_time 双口径 |
| 硬件 / 随机性 | 同机、同解释器、同种子协议 | 3 种子，报均值 ± 标准差 |

**操作性定义**：
- **相当**：主任务（语言建模 bpc）与对照 Transformer 差距 ≤10%，且 ≥2 项结构化任务显著占优；
- **更强**：主任务持平或更优，且 ≥3 项结构化任务显著占优。

### 组合效应（重要）

| 组合 | 结果 | 结论 |
|---|---|---|
| T3.2 + T3.4 + ②（旧 19,013 字符语料） | **114.70（−2.0%）** | **增益不叠加**：三者同作用于读出/记忆通路，差于 T3.2 单点 0.4%（在噪声带内） |

> 22,420 语料下未重跑组合项。值得记录的观察：**三项检索/记忆增益的排序在各轮语料上反复互换**
> （首轮 19,013：T3.2 −2.4% > T3.4 −1.0% > ② −0.8%；22,420：② −1.34% > T3.4 −0.71% > T3.2 −0.65%；
> 23,451：② −1.5% > T3.2 −1.1% > T3.4 −0.2%；**冻结 23,504：T3.4 −1.6% > ② −1.4% > T3.2 翻转 +3.2%**）。
> T3.2 的符号翻转是决定性的：**检索融合增益不可依赖，明确移出推荐**；T3.4 与 ② 四轮均为增益（幅度 −0.2% ~ −1.6%）。
> 这与"不叠加"是同一件事的两面：它们冗余地作用于同一条读出/记忆通路，谁排第一取决于语料，
> 不应据此反复改推荐配置。泛化探针（§5.4《性能评估》）进一步证实 T3.4+② 组合对近域泛化有 −1.8~−2.2% 的额外收益、对远域 OOV 覆盖墙无效。

**总判读**：PPL 增益**全部来自检索/记忆通路**（当前稳定项为 T3.4 内容寻址与 ② 回放稳定读出）；
表征可塑性五类尝试在 M1/M8/M9 多轮中**全部为负**——
"冻结表征"（`eta_pc = 0`）是当前的硬约束，也是所有 PPL 收益的天花板。

## 四、推荐训练配置（M9 定稿）

```

  （T3.2 常态 top-k 检索融合已移出推荐：冻结语料 +3.2% 有害，四轮符号不稳）
穿插    sleep()：周期触发；T4.4 验证驱动为可选项（PPL 中性）
```

**明确不建议启用**（括号内为冻结语料 23,504 字符实测值，未重跑者沿用旧值）：
T3.2（**+3.2%，符号翻转**）、T2.2（**+18.4%**）、T4.3（+4.2%）、③（**+62.9%**）、
解冻类（V4′ **+23.1%** / ① **+22.0%** / ①+T1.2 **+22.0%**）、复制任务双向校验（−9.9pp）。

> ⚠ **T3.2 结案**：四轮增益为 −2.4% → −0.65% → −1.1% → **+3.2%（有害）**，符号翻转证明其"增益"

> 应被理解为**同一条通路的两种微实现**。

**铁律**：所有新行为以 config 开关承载且**默认关闭**，保证默认路径逐位不变；`tests/run_tests.py` fast 11/11 是零回归证据。

## 七、评测协议摘要

| 组 | 配置 | 角色 |
|---|---|---|
| 统计基线 | 3-gram / 5-gram | 下界 |
| **主对照** | nanoGPT 级 Transformer 0.44M / 2.22M（torch CPU） | 判定"相当/更强"的唯一标准 |
| 消融组 | 去掉各 T 项的降级版 | 收益归因 |
| 能力特化组 | 预训练 LLM few-shot（仅结构化任务） | 互补定位 |

六项任务：① 语言建模（主，bpc）② 长程依赖 ③ 单样本关联记忆 ④ 持续学习（BWT）⑤ 多跳推理 ⑥ 效率。
统计：3 种子 + 配对 Wilcoxon（p<0.05）；验证/测试严格分离。
判定矩阵：**未达成** = 主任务差距 >10% 或无一结构化任务占优；**相当** = ≤10% 且 ≥2 项占优；**更强** = 持平/更优且 ≥3 项占优。

## 八、诚实的风险声明

1. **可能无法关闭的机制差距**：任意位置精确对齐/复制（注意力一步直达 vs 联想链串行）、>10⁴ 步窗口。长程任务打平即算达标。
2. **表征可塑性是硬约束**：五类尝试跨 M1/M8/M9 四轮全负，"冻结表征"不是调参失败而是当前配方的必要条件；在解锁（开放项 O2）之前，PPL 的天花板由检索通路决定。
3. **收益已实测，无待兑现的预期**：路线图内已无"预计有效但未验证"的条目。
   **2026-09-23 收口后更新**：O2 经 10 配置实测**判定表征可塑当前不可解锁**；
   O7 判定**瓶颈在数据预算**（数据轴 4k→16k 字符 −11.2%、幂律 β=0.085；参数轴 1.71M→17M 反而 +22.4%）；
   O6 敏感度排序证明**仅 3 个模块贡献 >1%**（词涌现 +177.5% / 稀疏 k-WTA +84.0% / WM +1.2%）。
   ⇒ 唯一可兑现的路径是**扩大预训练语料**（M7_Core 中文子集 ~75 万条 / ~1 GB 已就位）
   与 O1 的容量栈合并；架构层开关的边际收益已接近耗尽。
4. **两条叙述张力**：WM 槽位扩容 vs "类脑 7±2"、拓扑生长引导 vs "基因预连接"——口径已在文档中声明。
5. **numba 结论已更正**：numba 无编译 bug（此前是自检脚本缩放错误导致权重被截断为 0）；实测加速 n=8192/m=32 → **51.5×**。不要再声称 numba 有静默错编译。
6. **Transformer 欠拟合风险**：数据受限时须同步报告双方学习曲线，避免在 Transformer 曲线仍快速下降时宣布胜利。
7. **睡眠巩固在 LM 路径无影响**：LTM 通路与读出解耦，sleep() 对本路径的 PPL 不改变（T4.4 实测 ±0.0%）。

## 九、硬件生态适配

| 后端 | 状态 | 说明 |
|---|---|---|
| numpy / CPU | ✅ 默认 | 无加速器时走 numpy，零回归 |
