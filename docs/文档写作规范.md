# 文档写作规范（长期有效）

> 适用范围：本仓库**全部 20 份文档**（清单见 §3）。目的是**同一事实只有一处权威出处**、
> 数字永远带口径、不再出现「同一组数字抄在 4 份文档里然后漂移」。
> **数据截止：2026-10-02（P113）。** 与代码冲突时**一律以代码为准**，并回头修文档。

## 1. 硬性规则

1. **一个事实只在一处写**（见 §3 分工表），其它地方**链接引用**，不复制数字。
2. **数字必带口径**：机器（x86 8 核 / 昇腾 191 核）、档位（smoke / 1b / 1b_max / 30b）、
   版本（P 编号或 commit）、单位（ms/tok）。正例：`12.09 ms/tok（1b 档，昇腾 191 核 + NPU，
   P113，日志 -182721.log）`。⚠ **口径的完整形态还包括「哪一段日志/哪个工具」**——
   同一档位同一平台在不同 run 上可以差很多（P111 17.63 vs P113 12.09 就是同档位同平台）。
3. **每份文档开头必须写**：适用范围 + 数据截止日 + 相关文档链接。三项缺一不可。
4. **历史值必须显式标注**：写「旧口径 78.16 只存于 git 历史，不可混用」是好的；
   直接拿旧值做论据是不好的。
5. **表格只放并列事实**。有因果、有论证、有取舍的内容写成正文段落。
6. **中文正文 + 英文标识符**。命令、参数、字段名保持原样，不翻译。
7. **参数以源码为准**：写任何 CLI 参数前先 `grep add_argument` 核一遍，不照抄旧文档。

| **把 CPU/NPU 重叠的 `max` 值当实测** | 「12.09 → 7.83（1.55×）」是 `max(两侧)` 的**理论上限**，**不是实测**。⚠ 预测值式表述同样禁止（见上） |
| 「启用 torch 全栈训练/多卡推理」 | P30 已删除 `tools/train_torch_lm.py`（缺 7 项机制含 big_ltm）；**当前不存在全 torch 轨** |
| 「语料中文 95%」 | 远程分片实测 en 50% / unk 47%（实为代码）/ **zh 仅 2%**，标为待核 |
| **「Cython 核与 numba 核逐位等价」** | **不成立（P192）**。M2 numba 核带 `fastmath=True`；M3 未开 fastmath，但 fp64 中间值与 Cython fp32 也会产生差异（有 FMA 收缩 + 重结合），Cython 用 `/O2`（严格 IEEE）→ 实测差 **~1 ulp**（max\|d\| 1e-8~1e-5，视规模）。门禁 `gate_cython_kernels.py` **分两档**：语义级严、数值级容差并如实打出 `max\|d\|` |
| **「读出流水能把 12.09 降到 7.83」** | **前提已被 P117 推翻**：训练步设备路径本就走 `forward_dev`（零同步）+ `nll_sync_every=8`（摊薄 `.item()`），**但不能由静态代码证明额外流水收益为零；尚无保持语义的实现和 NPU 实测**。`--readout-pipeline` **已停用**（传了直接报错退出） |
| **「`--cann-dispatch` 是一项新优化」** | **不是**：P120 起 `TASK_QUEUE_ENABLE=2` / `COMBINED_ENABLE=1` **本就默认开**。该开关只做**生效核对**（官方列了两个静默失效条件：JIT 路径、`ASCEND_LAUNCH_BLOCKING=1`，都**不打日志**） |
| **「推理时 NPU 因 CPU 而空转」/「给推理加 CPU/NPU 流水」** | **提法本身要更正（P192）**。推理走 `readout(h)`，末行是 `y.float().cpu().numpy()` **硬 D2H**（`accel_readout.py:1089`）—— 因为 `model.py:391` 的 `_dev_readout` 要求 `learn=True`，推理 `learn=False` 恒不成立。更根本的是：**自回归生成下 token t+1 的输入就是 token t 采样出的结果**，CPU 与 NPU **天然串行**，无法重叠。相邻生成 token 有真实依赖；全量 y 回读与 host 采样是当前实现选择，设备端采样等仍可研究，需独立验证采样语义和性能。正确提法：「当前推理瓶颈在 D2H 与 host 采样」（x86 实测 host 采样段 ≈0.77 ms/token） |
