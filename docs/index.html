01它解决什么问题

Transformer 把「关联」建模为全局成对相似度（QKᵀ，O(T²·d)）、把「记忆」建模为无学习的 KV 缓存、 把「学习」寄托于非局部的反向传播。这三点都与生物智能的工作方式相去甚远。PHD-Net 逐条换成了类脑机制。

人脑做法

突触局部可塑性，无需全局梯度；每个突触只看自己两端

对应：全部学习规则局部化，无反向传播

稀疏放电

皮层任一时刻仅约 1–5% 神经元活跃，计算与能耗随活跃度而非总规模增长

对应：k-WTA 稀疏编码 SDR + 事件驱动计算

双系统记忆

海马快速一次性印迹，皮层缓慢统计巩固（互补学习系统 CLS 理论）

对应：双速率记忆（快权重 + 慢权重 EMA）

有限容量工作记忆

前额叶约 7±2 个槽位，基底核门控决定「什么值得记住」

对应：有界槽位 WM + 调制门控

层级预测

高层级向低层级发预测，低层级只上传预测误差（预测编码 / 自由能原理）

对应：生成-识别闭环的预测编码层级

神经调制

DA / NE / ACh 依意外与奖赏门控可塑性与编码-检索模式切换

对应：surprise z 分数全局调制标量

02架构与信息流

五条通路并行：前馈识别流、反馈预测流、横向关联流（层内 Hebbian + 跨时间步 STDP）、记忆流（WM ⟷ LTM）、调制流（预测误差 → 全局门控）。认知层 M7–M12 在基础架构之上提供语言理解、上下文、知识调用与生成。

03模块与大脑对应

12 个模块，每个都有明确的神经科学对应：7 个机制级同构、4 个功能级同构、1 个设计级对应。

M1稀疏编码器

输入经随机投影后 k-WTA 竞争，仅保留 top-k 胜者得到 SDR（稀疏分布式表示），典型激活率约 12.5%。

大脑：初级感觉皮层稀疏放电 + SST/PV 中间神经元侧抑制

M2预测编码层级

每层含识别（上行）与生成（下行）权重：上行传表示，下行传预测，层间只上传预测误差，推理时迭代精炼以逼近自由能最小。

大脑：V1→V2→V4→IT 层级预测编码（Rao & Ballard 1999；Friston 自由能原理）

M3时序关联核（STDP）

稀疏固定拓扑，每神经元 m 条出边；突触迹模型下 Δw = η·(P_pre·post − P_post·pre)₊，A₊ = 2·A₋ 的幅度不对称——「先响后响则增强，后响先响则抑制」。

大脑：海马 CA3 递归网络 + 皮层局部突触的脉冲时序依赖可塑性（Bi & Poo 1998）

M4a工作记忆

C 个槽位（默认 4），每步衰减模拟漏积分持续放电；写入由调制门控决定——只有「意外」的信息才占用槽位。

大脑：背外侧前额叶 dlPFC 延迟期持续放电 + 基底核-丘脑门控

M4b长期记忆（双速率）

快权重做一次性 Hebbian 印迹，慢权重在睡眠巩固阶段以指数滑动平均吸收快权重；检索用 Hopfield 式吸引子动力学，天然支持模式补全。

大脑：海马快速印迹 + 新皮层慢速巩固（CLS，McClelland 1995）；CA3 自动联想

M5神经调制器

底层预测误差范数经在线 Welford 标准化为 z 分数，门控学习率并切换编码/检索模式——「先见者学，重复者忘」。

大脑：蓝斑 NE / VTA DA 的意外与奖赏信号；基底前脑 ACh 的模式切换（Hasselmo）

M6读出头

h = [r_L ; WM ; 召回结果]，感知器式局部规则学习；监督信号仅存在于最末端，主干完全无监督。

大脑：IT → 前额叶 / 前运动皮层的决策读出

M7组合编码器（词汇涌现）

字符 SDR 经 STDP 链绑定为词级表示；工程实现为无词典统计分词（n-gram 频次 + 左右边界熵判据），词表由语料自动涌现。

大脑：视觉词形区 VWFA 的组合调谐 · 已实现

M8情景缓冲

逐模式寻址的事件序列存储，任意历史事件可作线索链式回放恢复顺序——时间由连接承载，无位置编码。

大脑：海马情景记忆 + Baddeley 情景缓冲

M9语义关联图

三元组 (s, r, o) 以组合线索印迹 W += η·outer(o, [s;r])；检索一次矩阵-向量乘完成，无需注意力打分。

大脑：海马-皮层语义网络 + 扩散激活

M10分层摘要

句级→段级→篇级递归压缩，各层独立衰减率，形成「细节易逝、要旨长存」的记忆梯度。

大脑：记忆要旨与细节的双分离

M11生成解码器

工作记忆主题锚定 + 读出分布 + 温度 τ 采样（对应神经噪声与变异性），自回归但条件化机制不是注意力。

大脑：内言语与运动皮层生成通路

M12联想链推理

state ← WM；for r in 链: state ← query(state, r)；结果回填再检索——逐步推理 = 联想链展开。

大脑：扩散激活式联想推理（与思维链功能同构、机制不同）

M13上下文漂移情景记忆长程依赖

上下文随经历缓慢漂移（c ← ρc + (1−ρ)item）并印迹「上下文→项目」；回忆时内容寻址检索，回忆出的项目又驱动上下文继续漂移 → 串行顺序回忆自然涌现。配套：事件边界触发回放 + PFC 免衰减保持槽 + DG 模式分离。

大脑：时间上下文模型 TCM / CMR（Howard & Kahana；Polyn 2009）+ 齿状回模式分离 + 前额叶延迟期活动
实测：延迟复制位置准确率 n=4/8/16 = 45.6% / 25.9% / 17.8%（随机 8.3%，字符级 LM 基线 ~10%）

04学习规则总表

全部为局部规则：每个突触的更新只依赖其两端神经元活性、局部迹，以及一个全局调制标量——无反向传播。

k-WTA 竞争s = top-k(normalize(u)) — 稀疏编码
Oja 规则Δw = η·y·(x − y·w) — 稳定的 Hebbian 特征学习，防发散
PC 误差规则ΔW_dn = η·e ⊗ r_hi — 生成模型拟合数据分布
STDP 迹Δw = η·(P_pre·post − P_post·pre)₊ — 时间因果结构学习
海马印迹W_fast += η_h·p_out ⊗ p_in — 一次性经验快速存储
皮层巩固W_slow ← (1−η_c)·W_slow + η_c·W_fast — 慢速统计学习（睡眠回放）
感知器读出ΔW_ro = η·(t − y) ⊗ h — 仅末端使用监督
调制门控η_t = η₀·σ(a·z(surprise)) — 全局可塑性调度

numba 结论更正（2026-09-18）

此前记录为「numba 0.67 对 STDP 核静默错编译」，经复检为误判：真实根因是自检脚本传 0.1·t_pre 而 LTD 项用完整 t_post，净增量恒负使权重被截断为 0，numba 与 numpy 两条路径同时失败（控制变量：错误缩放两者均 0.0000，正确缩放两者均 5.0000 —— 逐位一致）。自检已改为三重门槛并修复，现 NUMBA_OK = True，实测加速 n=8192/m=32 → 51.5×（0.046 vs 2.387 ms/步）、n=4096/m=64 → 5.83×。副作用：启用后序列误差 0.282 → 0.317、结构 cos 0.81 → 0.73（浮点分歧在 600 步在线学习中被放大），因果结构与其余指标保持。

  • O1 完整双栈统一：✅ 完成（2026-09-23）——① 容量栈合并：LM 栈挂 1B 事件驱动容量栈，ppl −1.83%（95.48 vs 97.26）、可塑参数 1.58M、容量上限 1.0B 突触；② 主干结构性稀疏连接（CSR 稀疏图 + numba）：连接率 3.1% 时 PPL 持平（+0.03%）、突触存储压缩 32×、PC 层加速 1.68–4.02×，与稠密栈数值等价（≤1.1e-15）；③ 关键区分：「稠密矩阵 + 稀疏更新」≠「结构性稀疏连接」——后者才对应皮层 dense representation + sparse connectivity。
  • O2 表征可塑性解锁：10 配置实测 → 当前不可解锁——最优组合（稳态 + 发育冻结 + 回放 + 退火）仍 2.55× 劣于冻结基线，stdp_homeostasis 单独启用即发散（3.9×10⁴）。冻结表征仍是必要配方。
  • O3 100B 在线 CSR 迁移：1B 档验证完成（内存 91.8 → 16.0 B/条目，5.74×↓；分片落盘 round-trip 逐位一致）；100B 即便 int8 亦需 ≥0.9 TB → 本机不可验证（结构就绪、规模受限）。
  • O4 分词器向量化：完成——36.9× 加速（7,035 → 191 ms，23,504 字符），3 组超参下 vocab 与 tokenize 输出逐元素一致。

  • O6 脑同源机制功效消融：完成——14 配置敏感度排序：词涌现 +177.5%｜稀疏 k-WTA +84.0%｜WM +1.2% 为真贡献；M5 调制器 −4.2%（净负担）；M3 STDP −0.004%、M4b LTM 0.000% 属装饰/中性。

07与人脑：机制同构，而非相同

可以确认的是「机制级同构的功能性缩比模型」，不能确认「与人脑架构相同」——12/12 模块有神经认知对应；2026-09-19 已将 10 个实现级差异中的 5 个（突触类型/调制系统/可塑性/发育/睡眠）统一为脑同构（默认关闭、零回归），剩余 5 个（规模/计算基底/具身/胶质/能效）仍大幅简化。

同构层（可确认）

  • 稀疏编码 ↔ 皮层稀疏放电与侧抑制 WTA
  • 预测编码层级 ↔ 皮层层级预测编码 / 自由能原理
  • STDP 突触迹 ↔ 脉冲时序依赖可塑性
  • 工作记忆槽位与门控 ↔ dlPFC 持续放电 + 基底核门控
  • 双速率记忆 ↔ 海马快印迹 + 皮层慢巩固（CLS）
  • 吸引子检索 ↔ CA3 自动联想
  • 调制门控 ↔ NE / DA / ACh 弥散投射
  • 情景缓冲 ↔ 海马情景记忆；语义图 ↔ 扩散激活
  • 生成解码 ↔ 内言语与运动生成通路
  • 联想链推理 ↔ 扩散激活式逐步推理

差异层（剩余 5 项不可称相同）

  • 规模：人脑约 860 亿神经元 / 10¹⁴–¹⁵ 突触 vs 本项目 1,677 万神经元 / 10⁹ 容量
  • 计算基底：脉冲时序 + 树突非线性 + 神经振荡 vs 速率编码矩阵运算
  • 具身与多模态：全身感觉运动闭环 vs 单通道符号输入
  • 胶质细胞与神经肽体积传导：完全缺失
  • 能效：人脑 20 W 完成全部认知功能

已统一为脑同构（2026-09-19，默认关闭）

  • 突触类型：新增 E/I 分型（抑制性出边权重为负、侧向抑制）
  • 调制系统：单标量 z → 四通道 ACh/NE/DA/5-HT
  • 可塑性：稳态缩放扩展至 STDP + BCM 元可塑性滑动阈值
  • 发育：新增临界期（经验衰减学习率）+ 突触修剪
  • 睡眠：新增 SWS/REM 分期 + 突触 downscaling

08规模对标：PHD-Net 100B vs GLM-5.3-Flash（320B-A18B MoE）

这一节的数字不全是实测：GLM 侧为公开事实（引用），PHD-Net 侧为推算，能力维度为估算（借 Transformer α≈0.34 外推）。之所以仍要写，是因为「100B」这个词必须先定义清楚，否则比较毫无意义。

先解决口径：两种「参数」不能直接比大小

口径PHD-Net 100BGLM-5.3-Flash含义
存储口径~10¹¹ 条可塑突触（稀疏按需，未触碰不落盘）320B 总参数（FP8 ≈305.8 GiB）谁占多少介质
每步激活~5×10⁴ 条突触（≈2×10⁵ FLOPs/token）18B 激活（≈3.6×10¹⁰ FLOPs/token）真正的算力差：约 5 个数量级
稠密可训练版本 A ~0.2M（已被 M4 证伪）｜版本 B ~20M全部 320B「可训练」才是主口径

「100B」的三种定义：A 仅容量放大（LM 栈不变，M4 已证明不产生收益）、B 按比例放大（~20M 稠密，需 T5.1-lite 才能压住 O(n²)）、C = B + 10⁸–10⁹ token 经验。三者能力完全不同，混用即无效比较。

能力维度：三情景外推（估算，非实测）

悲观 · 版本 APPL 100–120

关键假设列在《竞争力与脑同构性评估》§2.5。诚实校准：PHD-Net 目前只有 ~0.2M 一个稠密数据点，无自身 scaling curve，上述外推必须被下面三组实测证伪或修正。

要让预估可证伪，必须先补的三组实测

  • PHD-Net scaling curve：固定配方跑 0.2M / 2M / 20M 三点，拟合 α（当前完全缺失）。
  • 表征可塑性解锁：在解锁前，capacity→capability 的转化率为 0，任何外推都只是 resource 故事。
  • 100B 在线 CSR 可行性：现 dict 邻接约 100+ B/条目，100B 规模不可行；需先做 int8 + 定长 CSR + mmap 分片。

结论：100B 只会放大容量，不会自动转化为能力——缺的是「把容量转成能力的可塑机制」。在 O2 解锁之前，任何 PPL 数字都只是 resource 侧的胜利。
