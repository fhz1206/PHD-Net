预测编码 × Hebbian × 双记忆
一个完全不依赖自注意力的类脑架构

PHD-Net 把「关联」交给突触局部可塑性（STDP）、把「记忆」交给事件驱动的稀疏突触表 （海马快印迹 + 皮层慢巩固）、把「抽象」交给预测编码层级——全程无自注意力、无位置编码、无堆叠层， 每个机制都有明确的神经认知对应，稀疏性是架构原则而不是优化手段。

01它解决什么问题

Transformer 把「关联」建模为全局成对相似度（QKᵀ，O(T²·d)）、把「记忆」建模为无学习的 KV 缓存、把「学习」寄托于非局部的反向传播。这三点都与生物智能的工作方式相去甚远，PHD-Net 逐条换成了类脑机制。

突触局部可塑性

每个突触只看自己两端，无需全局梯度

对应：全部学习规则局部化，无反向传播

稀疏放电

皮层任一时刻仅约 1–5% 神经元活跃，计算随活跃度而非总规模增长

对应：k-WTA 稀疏编码（SDR）+ 结构性稀疏连接

双系统记忆

海马快速一次性印迹，皮层缓慢统计巩固（互补学习系统 CLS）

对应：事件驱动稀疏表 + 双速率巩固

有限容量工作记忆

前额叶有限槽位，基底核门控决定「什么值得记住」

对应：有界槽位工作记忆 + 调制门控

层级预测

高层级向低层级发预测，低层级只上传预测误差（自由能原理）

对应：生成-识别闭环的预测编码层级

神经调制

DA / NE / ACh 依意外与奖赏门控可塑性与编码-检索切换

对应：surprise z 分数全局调制标量

02六机制与神经认知对应

每个机制都必须说得出对应的真实神经现象——这是准入条件，不是事后修饰。 认知层（M7–M13：词汇涌现、情景缓冲、语义关联图、分层摘要、生成解码、联想链推理、上下文漂移记忆） 在六机制之上覆盖 LLM 的四项核心功能。

M1稀疏分布式编码

输入经感受野投影后做 k-WTA 竞争，只保留 top-k 胜者得到 SDR。相似输入 → 重叠支撑集， 这是稀疏分布式编码承载泛化的方式。

大脑：初级感觉皮层稀疏放电 + SST/PV 中间神经元侧抑制与 WTA 竞争

稀疏性：输出 12.5% 活跃（k-WTA）

M2预测编码层级

每层含识别（上行）与生成（下行）权重：高层发预测、低层只上传误差，推理时迭代精炼逼近自由能最小。 权重以 CSR 承载，不存在的突触不存储、不计算。

大脑：V1→V2→V4→IT 层级预测编码（Rao & Ballard 1999；Friston 自由能原理）

稀疏性：CSR 结构性稀疏，连接率 12.5%

M3STDP 时序预测

稀疏固定拓扑 + 突触迹：Δw = η·(P_pre·post − P_post·pre)₊，截断于 [0, w_max]。 直觉是「先响后响则增强，后响先响则抑制」——网络自发学到时间因果结构。

大脑：海马 CA3 递归可塑性 + 皮层局部突触的脉冲时序依赖可塑性（Bi & Poo 1998）

稀疏性：每神经元 16 条出边 → 连接率 1.56%

M4a工作记忆

有界槽位 + 每步漏衰减（模拟持续放电的漏积分）+ 调制门控写入：只有「意外」的信息才占槽。 另有免衰减的摘要槽，对应前额叶对重要内容的主动维持。

大脑：背外侧前额叶 dlPFC 延迟期持续放电 + 基底核-丘脑门控

稀疏性：槽位硬上限 4（+1 摘要槽）

M4b大容量事件驱动稀疏表

表示经确定性哈希接入大空间，共激活神经元之间生长新突触（结构可塑性），检索由线索收敛到记忆。 每神经元出边数是硬容量约束；在线可写 CSR 存储与 dict 版逐位等价。

大脑：海马快速印迹 + 新皮层慢速巩固（CLS）；CA3 自动联想、齿状回模式分离

稀疏性：事件驱动（只触碰已生长条目）；1B 档容量 2²⁴×72 ≈ 1.208e9

M5神经调制

底层预测误差范数经在线 Welford 标准化为 z 分数，门控学习率并切换编码/检索模式—— 「先见者学，重复者忘」。可选四通道版本把单标量细化为 ACh / NE / DA / 5-HT。

大脑：蓝斑 NE 与 VTA DA 的意外与奖赏信号；基底前脑 ACh 的模式切换（Hasselmo）

稀疏性：零突触、零参数的全局标量广播

M6读出头

h = [顶层表示 ; 工作记忆 ; 时序预测特征]，softmax 感知器输出词表分布。 监督信号仅存在于最末端，主干完全无监督。

大脑：IT → 前额叶 / 前运动皮层的决策读出；皮层→输出是多级中继 + 群体编码

稀疏性：❌ 目前 100% 稠密 —— 明确的架构欠账（见下节）

03稀疏性是架构原则

「稀疏即效率」在本项目不是事后优化选项，而是从第一版就定下的组织原则： 人脑皮层的连接率约 2e-8、平均每神经元约 1744 条突触，任一时刻约 1–5% 神经元活跃。 既然如此声称脑同构，就必须逐项交代本架构的稀疏性账——包括不达标的那一项。

部件当前稀疏性状态
M1 编码输出k-WTA 稀疏，12.5% 活跃✅ 成立
M2 预测编码主干CSR 结构性稀疏，连接率 12.5%（conn_k=128 / n_in=1024）✅ 成立
M3 STDP 时序核每神经元 16 出边，连接率 1.56%✅ 成立
M4a 工作记忆槽位硬上限 4（+1 免衰减摘要槽）✅ 成立（有界）
M4b 大容量表事件驱动：只触碰已生长条目，未触碰不存不计算✅ 成立
M6 读出100% 稠密（对照人脑连接率 2e-8、每神经元约 1744 条突触）❌ 明确的架构欠账

关于 M6 的欠账，必须直说

读出是全项目唯一没有稀疏化的部件，与人脑连接率差 4 个数量级。 稀疏读出的朴素版本（每输出单元 k 条入边，CSR 承载）已经存在但未启用为默认—— 这是「吞吐换精度」的配方选择，不能替代架构上的稀疏化。 幂律稀疏化方案（把读出稀疏到 5–12% 活跃度）已设计、未实施， 是当前最高优先级的架构开放项。在它落地之前，任何「本架构稀疏度已达标」的说法都不成立。

组成规模占比

04四条铁律

违反任何一条就不是 PHD-Net。新增机制必须同时满足它们。

① 禁自注意力、禁位置编码、禁堆叠层
不出现 QKV 投影与全局成对相似度；不注入位置（「第 k 个位置」不存在于任何向量中， 顺序由 STDP 因果链承载）；不堆叠同构层（抽象由预测编码层级与分层摘要实现）。 代价是失去「任意两 token 一步直达」，收益是每步 O(活跃×m) 而非 O(T²·d)。
② 每个机制必须有明确的神经认知对应
不允许「工程上方便」的机制进主干。准入条件：能说清对应哪个真实神经现象、 为什么这个现象需要它。
③ 逐 token 语义 → 不允许批处理
状态跨 token / 分片 / epoch 连续演化，读出权重每步原地更新。 batch 化会破坏「每个样本都写同一份记忆」的记忆语义。并行只能来自部件内的稀疏结构， 不来自样本维。
④ 行为变更以 config 开关承载，且默认关闭
使「机制是否贡献」与「机制是否存在」成为两个可独立回答的问题。 两个例外（default-on）：sparse_conn（稠密 PC 栈已删除，传 False 直接 fail-fast）、 k_sparse（稀疏默认开启；评测脚本显式传自己的值，不影响既有口径）。
