Mechanisms

核心机制

每个机制都有神经认知对应，并落到具体实现文件。稀疏性是架构原则：人脑长程连接率 ~2e-8；本项目 M2 = 12.5%、M3 = 1.56%、M4b = 事件驱动、M1 k-WTA 12.5%、M6 = 4.2%。

M2预测编码

dense representation + sparse connectivity

上行识别与下行生成权重全部 CSR 承载，预测误差驱动更新。P194 起表征发育窗口：eta_pc=0.02 前 2 万步余弦退火到 0 后冻结（pc_dev_steps=20000），避免「表征漂移 × 恒定读出率」的灾难性遗忘。

实现 phdnet/sparse_pc.py稀疏性 12.5% 连接率

M3STDP 时序学习

稀疏拓扑突触迹

发放时间序决定突触增强/抑制，迹沿活跃通路累积。"fire together, wire together" 的算术形式。P192 修正了学习率语义（LTP/LTD 同乘 η），历史 PPL 锚点因此不可比。

实现 phdnet/plasticity.py + stdp_kernels.py稀疏性 1.56%（m_lateral=16）

M4双记忆

工作记忆 + 大容量印迹

M4a 保留当前上下文锚点（n_slots=4）；M4b 是 2²⁴×72 的事件驱动印迹表， 突触随经验生长而非构建即存在，每步计算量只正比于活跃神经元数——容量与算力解耦。

实现 phdnet/wm.py · bigltm.py · sparse_table.py容量 ≈1.208e9（占 1b 档 99.2%）

P197新颖性印迹

会话中学习（sdr_novelty）

SDR 支撑集新颖性检测（海马模式分离的工程等价）：新顶层激活模式 → 强制放行印迹门控。 LTM 印迹触发率 0.67% → 100%；cc_traces 3,000 token：PPL 2474 → 1308、 LTM 生长 +81%。配套 task_modulation / error_gated_memory / plateau_sleep / readout_replay 全默认开。

实现 phdnet/model.py::_sdr_novelty门控 ltm_imprint_gate 0.8→0.3

P194微批量（micro-batch）

读出梯度 B 步平均提交

--micro-batch（默认 1）：读出末端累积 B 步梯度后平均一次提交； 主干 / STDP / LTM 仍按 token 严格保序——脑同构对应微小神经元簇并行放电， 不破坏逐 token 时序语义。

实现 phdnet/readout.py commit_grad默认 1 = 逐步提交

P195fp8 主权重

DeepSeek-V4-Flash 模式

--readout-master-weight：低精度（fp8/bf16/fp16）只是影子副本—— 影子只做前向 GEMV（保带宽收益），所有更新落在 fp32 master（非目标行更新 100% 保留）， 每 8 步重量化。本机 A/B：fp8 无 master PPL 2.84 → 有 master 2.15（fp32 基线 2.14）。

代价 +866.7 MiB fp32（1b 档）默认 off

P198eta_oja=0 + 生成截断

发散防线 + 可读生成

eta_oja>0 会经「上行 Oja → PC 前向 → STDP/读出」正反馈发散： 生产规模 3,000 步 probe_PPL 9.1e11（=0 时 916）→ 库默认 0 + RuntimeWarning。 generate() 增加 top-k / nucleus(top-p) 截断——大词表小预算下它是 生成可读性的必要条件。诊断工具 tools/diag_vocab_budget.py。

Quick Start

跑起来

唯一生产训练入口是 train/train.py。全部开关与默认值见 train/README.md。

# 安装（numpy / numba / psutil / pyarrow / Cython 必装；torch 可选）
pip install -r requirements.txt

# 冒烟训练（分钟级，只验管线；smoke 档容量 < 1B 属预期日志）
python train/train.py --preset smoke --data sft --tokens 2000

# 英文终端（P199 消息目录后 --lang en 真正输出英文）
python train/train.py --lang en --preset smoke --data sft --tokens 2000

# P196：cc_traces 会话中学习（ModelScope 远程直读，零落盘）
python train/train.py --preset smoke --data cc_traces --remote-data --tokens 3000

# 标准 1B 档（本地 datasets/）
python train/train.py --preset 1b --data pretrain --tokens 1000000

# P195：fp8 影子前向 + fp32 主权重（默认 off）
python train/train.py --preset 1b --data pretrain --readout-dtype fp8 --readout-master-weight

# A/B 判据：固定探针集 probe_PPL（sliding PPL 信噪比不足，只能比 probe 差值）
python train/train.py --preset 1b --data cc_traces --probe-every 1000 --tokens 100000

# P198：训练前诊断词表预算（exposure = tokens / vocab）
python tools/diag_vocab_budget.py --vocab-sample-chars 300000 --tokens 400000

# 生成 / 对话（--topk 截断，默认 8）
python train/infer.py --model outputs/models/phdnet1b_1b_pretrain_final.npz --prompt "…" --topk 8
python train/infer.py --model outputs/models/phdnet1b_1b_pretrain_final.npz --chat

# 门禁：fast 9 项 + 47 个专项 verifier（gate_*.py 数量现查）
python tests/run_tests.py fast
ls tests/gates/gate_*.py

Honest Limits

已知边界（诚实）

以下每一条都经过本仓库实测验证，写在这里防止被性能声明误导。

1. 1B 档 PPL 仍高。词表 51,962 × 少量 token = 每词曝光不足。经验阈值 exposure = tokens / vocab：<30 严重不足（PPL 接近随机）、≥100 才充足 （tools/diag_vocab_budget.py 训练前估算）。
2. 「正常对话」未达到。1B 档生成 bigram 合法率仅 24–35%（3,392 词小词表 + 40 万 token 可到 78%，但那是缩小 6× 的目标空间）。接近正常对话需要 ≥10⁸ token 量级 曝光——这是数据量问题，不是算法问题。
3. eta_oja>0 是已知危险开关。上行识别权重 Oja 学习改 PC 前向 → 喂 STDP + 读出 → 正反馈发散：生产规模 3,000 步 probe_PPL 9.1e11（eta_oja=0 时 916）。 库默认 0；显式开启会收到 RuntimeWarning，仅限小规模机制测试。
4. 低精度默认是 fp32 而非 fp8/fp16。P110 实测：fp16 非目标行更新保留率仅 26.67% → 学习退化为纯 Hebbian。P195 主权重模式解除了它，但要多付一份 fp32 master（1b 档 866.7 MiB） 且引入 ≤N 步影子 staleness。
5. 幂律读出未接入加速器 / 历史锚点不可比 / 本机无 NPU。 --readout-powlaw-alpha>0 回落 numba（加速器对非均匀行宽 fail-fast，是正确行为）； P192/P193 修正 STDP 学习率语义属学习规则变更 → 旧 PPL 锚点只存于 git 历史； 所有昇腾端到端数字均为服务器历史实测（本机 x86 只能验管线），Cython 核无昇腾收益实测。
仍然成立的优势：9/9 fast + 47/47 门禁全绿；1M context 状态连续（跨 token/分片/epoch 不重置，显式里程碑证明）；每步计算量只正比于活跃神经元数（容量与算力解耦）； P197 会话中学习已让 LTM 真正参与训练（印迹触发 0.67% → 100%）。
