## 0. 设计动机

Transformer 把「关联」建模为**全局成对相似度**（QK^T，O(T²·d)），把「记忆」建模为**无学习的
KV 缓存**，把「学习」寄托于**非局部的反向传播**。这三点都与人脑的工作方式相去甚远：

| 人脑做法 | Transformer 做法 | PHD-Net 的选择 |
|---|---|---|
| 突触局部可塑性，无需全局梯度 | 反向传播（全局、非局部） | 全部学习规则**局部化**（每个突触只看自己两端） |
| 稀疏放电（~1–5% 神经元活跃） | 稠密激活 | **k-WTA 稀疏编码**（SDR，稀疏分布式表示） |
| 海马快印迹 + 皮层慢巩固（双系统） | 单一权重 + KV cache | **双速率记忆**：快权重（海马）+ 慢权重（皮层） |
| 前额叶有限容量工作记忆 | 上下文窗口随 T 线性/平方膨胀 | **有界槽位工作记忆** + 长期记忆检索 |
| 层级预测：高层级预测低层级输入 | 无生成式层级 | **预测编码层级**（自由能最小化） |
| 神经调制（DA/NE/ACh）门控学习 | 固定学习率 | **全局调制标量**门控学习率与编码/检索模式 |
| 连接率 ~2e-8、单神经元约 1744 条突触 | 稠密全连接 | **结构性稀疏连接**（不存在的突触不存储、不计算） |

四条总原则：

1. **无自注意力**：任何位置都不出现 QKV 投影与全局成对相似度计算；时序关联由**突触迹
   （STDP）**与**状态迹**承载，计算量与活跃神经元数成正比，而非与历史长度平方成正比。
2. **学习规则局部化**：每个突触的更新只依赖其前/后端神经元活性、局部迹、及一个全局标量
   调制信号——无反向传播。
3. **稀疏即效率**：全网络采用稀疏分布式码（SDR）与稀疏连接；激活与存储只触碰活跃通路。
   **稀疏性是架构原则，不是优化手段**——逐项账见 §3.
4. **双速率记忆**：一次性经验写入快权重（海马式印迹），统计规律缓慢巩固入慢权重（皮层式学习）。

## 1. 四条铁律

这四条是硬约束，违反即不是 PHD-Net。**任何新增行为都要同时满足它们。**

### 铁律一：禁自注意力、禁位置编码、禁堆叠层

- **不出现** QKV 投影、`softmax(QK^T/√d)V`、因果掩码注意力；
- **不注入位置**——「第 k 个位置」不存在于任何向量中，时间信息由 STDP 因果链与情景缓冲的
  链式回放承载（顺序即连接）；
- **不堆叠同构层**——抽象由预测编码层级（生成-识别闭环）与分层摘要实现，每层是独立
  脑区式模块，有自己的记忆与调制，而非同一残差流的重复块；
- **梯度不跨机制**——误差信号只到最末端感知器（读出），不反传进 M1–M5（见铁律二）。

代码体现：M2 的层是 `SparsePCStack` 的 4 个**异质**映射（上行生成 + 下行识别），
非同构堆叠；全仓无 QKV 投影结构。

### 铁律二：每个机制必须有明确的神经认知对应

不存在「工程上方便但无认知对应」的模块。六机制各自对应一个可指名的生理结构
（详见 §4 每小节开头的「脑对应」行）。**无法指名认知对应的新增机制一律拒绝。**

学习规则同样必须局部：每个突触只看自己的前/后端活性与局部迹，**没有全局梯度**。
监督信号只存在于最末端的读出感知器，且以局部误差（交叉熵对末层权重的梯度）形式作用于
该读出权重——不回传到 M1–M5。误差只通过 M5 的**标量门控**影响 M1–M3 的**学习率**，
不携带方向信息。

### 铁律三：逐 token 语义 → 不允许批处理

**状态跨 token / shard / epoch 连续演化**，具体指以下持久状态每步原地更新、
**从不重置**：

| 状态 | 位置 | 每步行为 |
|---|---|---|
| 读出权重 `W` | `phdnet/readout.py` | **原地更新**（rank-1 AXPY / `addmm_`），下一步必须看到更新后的 `W` |
| STDP 突触迹 | `phdnet/plasticity.py` | 迹衰减 + 累积，跨步连续 |
| 调制器 Welford 统计 | `phdnet/modulator.py` | 在线更新 `mu`/`m2`，z 分数依赖历史 |
| WM 槽位强度 | `phdnet/wm.py` | 漏积分衰减 + 门控覆写 |
| M4b 表 | `phdnet/sparse_table.py` | 事件驱动生长，跨步/epoch 累积 |
| `step_count` / `_exp` | `phdnet/model.py` | 单调递增，驱动临界期与睡眠节律 |

由此推出两条硬约束：

1. **不允许批处理**。批处理会改变 `W` 的更新次数与更新顺序 → 改变训练语义。
   这是**架构约束**，不是实现选择（详细论证见《并行与加速架构分析》§一）。
2. **上下文长度不构成内存约束**（状态是固定大小的迹与槽，不是 KV 缓存），
   但**状态不可预计算**（每步都被前一步改写）→ 预计算类优化收益极小。

`--epochs > 1` 时 `net` 不重置，日志显式打印 `state continuous (net not reset)`；
仅每段首步切断上一个分段的前词链接。

### 铁律四：行为变更以 config 开关承载，且默认关闭

**例外**（默认开，因为它们已是主路径且逐位等价于被取代的旧实现）：

| 开关 | 默认 | 例外理由 |
|---|---|---|
| `csr_online` | **True** | 在线可写 CSR 是 M4b 主路径；dict 邻接表已降级为短跑/调试选项（`--no-csr-online`）。两版 `predict`/`learn` 逐位等价，由 `tests/verifiers/verify_csr_equiv.py` 保证 |
| `k_sparse` | **非 0**（`max(8, n_sdr//8)`） | k-WTA 稀疏编码是 M1 的定义本身，不是可选项 |
| `sparse_conn` | **True** | 2026-09-28 起主干唯一实现是 `SparsePCStack`；稠密栈已删除，传 `False` 在配置期 fail-fast（`phdnet/config.py::__post_init__`） |

其余全部行为开关默认 `False`/`0`，且注释中标注「默认关闭 = 旧行为（非破坏）」。

`readout_dtype` 是唯一需要区分「库默认」与「CLI 默认」的字段（fp16 vs bf16），
因为它是**精度**而非**行为**开关——见 §7.1。

## 2. 数据流与状态演化

### 2.1 端到端数据流

```
文本（字符流）
  │
  ├─ 词级分词：CSR-trie 贪心 + δ 前缀链（numba nogil 多线程）
  │            小词表 CSR 二分 / 大词表边哈希（阈值 2 万边，best-of-3）
  │            → 词 id 序列（词表由训练语料涌现，非人工词表）
  │
  ├─ 复合 SDR 编码：x = [当前词 SDR(n_sdr) ; 前词 SDR(n_sdr)] → 2·n_sdr 维
  │            （`encode_composite`，预分配复用 fp32 缓冲，OOV 整步跳过）
  │
  ├─ M1 稀疏编码：k-WTA top-k（k = n_sdr/8）→ s0（SDR，仅 k 个非零）
  │
  ├─ M2 预测编码：SparsePCStack 4 层 CSR（conn_k = n_in//8）
  │            生成权重 W_up + 识别权重 W_dn，误差驱动 + Oja
  │            → r2（顶层表示）+ e0（底层预测误差，驱动 surprise）
  │
  ├─ M3 STDP 时序预测：Δw = η·(P_pre·post − P_post·pre)₊，迹 λ 衰减
  │            → pred（下一时刻发放率预测，诊断 + 可选读出特征）
  │
  ├─ M5 神经调制：surprise = ‖e0‖/√dim → Welford z → gate = σ(a·z) → mode
  │
  ├─ M4a 工作记忆：门控写入 + 漏积分衰减（gamma）+ 摘要槽（免衰减）
  │
  ├─ M4b 事件驱动稀疏表：imprint（encode 且 gate > 0.8）/ recall（retrieve）
  │            2²⁴ 神经元 × 72 出边，事件驱动生长「fire together, wire together」
  │
  ├─ M6 读出：h = [r2 ; WM ; STDP 预测] → W·h → softmax 感知器
  │            交叉熵末端梯度**原地更新 W**（逐步，非批处理）
  │
  └─ Hebbian/局部更新：PC 学习、STDP 学习、编码器学习（均 × 调制门 mod_scale）
```

**关键点**：M6 的 `W` 更新是**链式的核心**——`token t+1` 的读出必须看到 `token t` 更新后的
`W`。这是铁律③的直接体现，也是「不允许批处理」的根源。

### 2.2 五条通路

| 通路 | 走向 | 承载 |
|---|---|---|
| 上升（生成） | `s0 → r1 → r2` | M2 `W_up`：高层预测低层输入 |
| 下降（识别） | `r2 → r1 → s0` | M2 `W_dn`：误差驱动修正，权重更新只发生在此 |
| 时序 | `rate(t-1) → rate(t)` | M3 STDP 迹，跨 token 因果链 |
| 记忆 | `r2 → WM/LTM → 读出` | M4a/M4b，跨 token/跨段召回 |
| 调制 | `e0 → gate → 全部学习率` | M5，全局标量广播（不携带信息，只携带门控） |

### 2.3 状态连续演化（铁律三的直接后果）

- **跨 token**：`_prev_rate`（STDP 迹）、`_task_gate`（滞后一步任务门控）、
  `_prev_pc`（时序预测目标）、`W`（读出权重）每步原地更新；
- **跨 shard**：分片切换不重置 `net`，`step_count` 连续；
- **跨 epoch**：`--epochs > 1` 时 `net` 不重置。

**不变量**：`readonly=True` 时**所有**持久状态被冻结（WM/LTM/STDP 迹/调制器/计数器），
仅做前向推理——保证评估可复现。2026-09-28 修复了 `readonly` 未冻结学习块的历史偏差
（此前 PC/STDP/编码器学习、`_prev_rate`/`_exp` 仍被改写）。

### 2.4 单个时间步的推理与学习顺序

`PHDNet.step()`（`phdnet/model.py:201`）的执行序：

1. M1 `encode` → `s0`；M2 `infer` → `cache{r2, e0}`
2. `_rate(r2)`：半波整流 + k-WTA（k = len//16，~6% 激活）→ `rate`
   ——稀疏化是 M3 STDP 正确工作的前提（低激活率保证不同输入的支撑集区分度）
3. M3 `predict(_prev_rate)` → `pred`；`cos` 相似度 → `seq_err = 1 − cos`
4. M5 `observe(surprise)` → `gate`, `mode`
5. M4a `decay()` + `write(r2, mem_gate, thresh)`
6. M4b `imprint`（条件触发）或 `recall`（条件触发）
7. `_build_h(r2, pred_feat, fused)` → 读出 `forward_dev` → `learn_softmax`（**W 原地更新**）
8. 全模块局部学习 × `mod_scale = (0.3 + 0.7·gate) · task_scale · cp_scale`

## 3. 稀疏性账（架构原则，不是优化手段）

**人脑参照**：皮层连接率 **2e-8**、每个神经元突触数**约 1744**、神经元活跃率 ~1–5%。

### 3.1 本项目逐项对照（1B 档，n_sdr = n_mid = n_top = 1024）

| 部件 | 结构 | 连接率 / 活跃率 | 状态 |
|---|---|---|---|
| M1 稀疏编码 | k-WTA top-k | `k_sparse/n_sdr = 128/1024` = **12.5%** | ✅ 稀疏 |
| M2 预测编码主干 | CSR，每神经元 `conn_k` 条**存在**入边 | `128/1024` = **12.5%** | ✅ 结构性稀疏 |
| M3 STDP 时序核 | 每神经元 `m_lateral` 条出边 | `16/1024` = **1.56%** | ✅ 稀疏拓扑 |
| M4a 工作记忆 | 4 个槽位，有界 | 固定 4 行 | ✅ 有界容量 |
| M4b 事件驱动稀疏表 | 在线 CSR / dict 邻接，**事件驱动生长** | 每神经元 ≤ 72 出边，**已生长**才算存在 | ✅ 稀疏 + 结构可塑性 |
| **M6 读出** | **稠密 `vocab × 3072`** | **100%** | ❌ **架构欠账** |

M1/M2 的 12.5% 口径说明：`k_sparse` 与 `conn_k` 均为 `n//8`，因此**激活率**与**连接率**
在此档位下同为 12.5%。

**M4b 的稀疏性是动态的**：容量 2²⁴×72 是**上限**，不是构建即存在的突触。
突触随经验生长（结构可塑性），`count_params` 只计**已生长**数。
训练初期利用率极低（`tools/train_1b_capacity.py` 的小规模演示中，
1500 步后仅生长 3,072 条 = 容量上限的 0.00031%）。

### 3.2 M6 读出欠账（必须直说）

**M6 读出目前 100% 稠密**，这是**明确的架构欠账**，不是实现选择：

- 人脑连接率 2e-8、每神经元约 1744 条突触；本项目读出每个输出单元接收**全部 3072 条入边**；
- 这不只是同构债，也是**访存债**——读出 W 是每步访存的主体
  （量级论证见《并行与加速架构分析》§三）；
- `--readout-conn-k > 0` 提供了 CSR 稀疏读出的**结构性**实现（默认 `0` = 稠密），
  但**当前主路径未启用**，且目标稀疏度（幂律）**已设计、未实施**；
- 因此本文的稀疏性账在此处**不闭合**：M1/M2/M3/M4b 稀疏，M6 稠密。

### 3.3 1B 档容量账

「1B 模型」= **总突触参数容量 ≥ 1.0×10^9**。按
`train/config_1b.py::capacity_report()` 的算术口径（1B 预设，词表 51,962）实算：

| 部件 | 口径 | 突触数 | 占比 |
|---|---|---|---|
| M4b 大空间表 | 容量上限（2²⁴×72，事件驱动） | 1,207,959,552 | **88.158%** |
| M6 读出（稠密） | `51,962 × 3,072` | 159,627,264 | **11.650%** |
| M1 编码器 | `2·n_sdr × n_sdr + n_sdr` | 2,098,176 | 0.153% |
| M2 主干 CSR | 4 层 × `n_out × conn_k` | 524,288 | 0.038% |
| M3 STDP | `n_top × m_lateral` | 16,384 | 0.001% |
| **合计** | | **1,370,229,664 ≈ 1.370e9** | 100% |

**稀疏 : 稠密 = 88.198% : 11.802%**（稀疏 = M2 + M3 + M4b）。

读出规模 `51,962 × 3,072` 在 bf16 下 = **319.3 MB**，是每步访存的主体。

> **诚实边界**：`count_params` 计入的是**已生长突触数**（M4b 按已生长计，非容量上限），
> 训练初期远低于上表。上表是**容量上限**口径，用于验算「≥1B」这一档位定义。
> 启动时打印的「突触参数容量验算」即此表。

> ⚠ **与旧文档的差异**：早期文档记1.317e9、稀疏 88%、读出 11.6%。占比一致，
> 但**绝对值已随 `big_ltm_m`（60→72，1.2×）与词表口径变化**。以本文实算的
> **1.370e9** 为准（`capacity_report` 直接算术输出）。

## 4. 六机制与学习规则

### 4.1 M1 稀疏分布式编码器 `SparseEncoder`

**脑对应**：初级感觉皮层的稀疏放电与抑制性侧抑制（k-WTA 竞争）。

```
u = W_enc·x + b                全层电位（感受野投影）
s_i = norm(u_i)  若 i ∈ top-k，否则 0     → SDR 稀疏分布式表示
```

| 项 | 值 | 出处 |
|---|---|---|
| 库默认 `n_sdr` / `k_sparse` | 256 / 16（**6.25%**） | `phdnet/config.py` |
| 1B 档 | 1024 / `max(8, 1024//8)` = 128（**12.5%**） | `config_1b.py::build_cfg` |
| 权重存储 dtype | 默认 **fp64**（`encoder_dtype`），迭代量恒 fp32 | `config.py:299` |
| 激活平台自适应 | aarch64 → 自写 numba GEMV；x86 → BLAS | `sparse_encoder.py:110` |

**k 值的选取依据**（库默认注释记录的实测）：`k=16`（6.25%）优于 `k=32`（12.5%）；
`k=8`（3.1%）因容量不足反而有害。1B 档按 `n_sdr//8` 放大到 128，维持 12.5% 口径。

**为什么默认 fp64 而读出用 fp16**：M1 是 GEMV，`W.dtype == x.dtype` 必须成立，
否则 numpy 脱离 BLAS 走逐元素慢路径。读出侧的半精度学习精度问题由
`readout_dtype` 单独解决，M1 不承担「更新被舍入」的语义（详见 §7.2）。

**学习**（T2.2 可学习稀疏词典，默认关闭）：仅活跃行更新
`ΔW_i = η·s_i·(x − s_i·W_i)`，随后行范数拉回初始值（Foldiak 稳态双约束）。
局部性：成本 `O(k·n_input)`，无全局非局部梯度。

### 4.2 M2 预测编码层级 `SparsePCStack`

**脑对应**：皮层生成-识别闭环（高层预测低层输入，误差驱动修正）。

**结构性稀疏**（不存在的连接不存储、不计算，不是零权重矩阵）：
层结构 `n_sdr→n_mid→n_top→n_mid→n_sdr`（4 个**异质**映射：2 上行生成 + 2 下行识别）；
每神经元入边 `conn_k = 128`（`n_in//8` = **12.5%**，CSR 存储）；
推理步数 `n_infer_steps = 1`（误差驱动精炼 = 自由能下降迭代）；
权重上限 `pc_w_max = 2.0`（与 STDP 的 `w_max = 1.0` 是独立字段）；
核选择 `pc_fused_kernel`，CLI `--m2-kernel` 默认 `plain`（平台差异见性能文档）；
1B 档 `eta_pc = eta_oja = 0`（表征冻结，多轮实测最优解）。

**学习规则**（全部局部，无反向传播）：
- 生成权重：`ΔW_up = η·e⊗post`（误差驱动）
- 识别权重：`ΔW_dn = η·(pre − post·w)`（**Oja**：Hebb + 归一化，防发散）
- 稀疏外积核 `_csr_add_outer`、稀疏 Oja 核 `_csr_oja_up`，均按行 `prange` 并行；
  `ai == 0` 的行整行短路（减 0 不改变任何值）。

**可复算的性质**：`k = n_in`（全连接图）时与稠密栈数值一致；CSR 求和按列索引升序，
与 BLAS 内部求和顺序不保证逐位相同（容差 1–2 ulp 级，由专项对拍保证）。

### 4.3 M3 STDP 时序预测 `STDPCore`

**脑对应**：海马 CA3 递归网络与皮层局部突触的 STDP（时序可塑性）。

```
稀疏拓扑：每神经元仅 m 条出边（m_lateral = 16 → 1.56%），复杂度 O(活跃×m)
突触迹：  P_pre ← λ·P_pre + pre ；  P_post ← λ·P_post + post   （λ = 0.35）
更新：    Δw = η·(P_pre·post − P_post·pre)₊  ，截断于 [0, w_max]
```

1B 档：`n_top = 1024`、`m_lateral = 16`（每神经元 16 条随机出边，不放回抽样）
→ **连接率 1.56%**；`lambda_trace = 0.35`（时间窗宽度，过宽会引入隔步混淆）；
`eta_stdp = 0.02`（库默认 0.03）。

**M3 在架构中的双重角色**：

1. **时序预测**：`predict(prev_rate)` 给出下一时刻发放率预测 → 诊断指标 `seq_err`
   （`1 − cos(pred, rate)`），并作为读出特征（`pred_in_readout` 时进入 `h`）；
2. **因果链承载**：迹跨 token 连续，是「顺序即连接」的实现——**位置信息只存在于
   突触迹里，不存在于任何向量中**（铁律一）。

**执行后端**：**只走 numpy(+numba) CPU**（P30 定稿）。旧 torch 后端已删除，
因为 STDP 的逐突触状态（自适应 LR / 稳态 / 元可塑性 / E-I）在 torch 上无法保留，
迁移会丢机制。`backend` 显式指定非 `auto/numpy/cpu` 时**直接抛错**而非静默降级。

**可选增强**（全部默认关闭）：逐突触自适应 LR（局部二阶矩归一）、
多尺度双迹（短窗 LTP + 长窗巩固）、稳态突触缩放、BCM 元可塑性（滑动阈值 θ 门控）、
E/I 突触类型（抑制性出边权重为负，`ei_ratio = 0.2`）。

### 4.4 M4a 工作记忆 `WorkingMemory`

**脑对应**：背外侧前额叶的持续放电 + 基底核门控写入 + 主动维持（rehearsal）。

槽位数 `n_wm_slots = 4`（有限容量，≈7±2 的抽象）；漏衰减 `gamma_wm = 0.85`/步
（持续放电的自然消退）；写入门限 `gate_thresh = 0.35`（基底核门控假说：仅
`gate > thresh` 才写）；摘要槽由 `wm_summary_every` 触发（默认 0 = 关闭）。

**三条设计要点**：

1. **漏整合 + 摘要槽**：普通槽每步乘 `gamma` 衰减；摘要槽**不参与衰减**，
   对应前额叶对重要内容的主动维持。每 `wm_summary_every` 步把当前内容经吸引子
   （LTM recall）压缩为稳定表示写入保留槽。
2. **写入目标排除摘要槽**：长跑衰减后所有槽强度都趋低，`argmin(strength)` 可能
   命中摘要槽并把「免衰减保护的重要内容」覆盖成无关输入 → `write` 与
   `_pick_weakest` 都显式排除 `summary_slot`。
3. **可选内容寻址**（T3.4，默认关闭，`wm_sim_thresh = 0.6`）：写入「与新内容余弦
   相似度达阈值的最相似槽位」，相似内容聚合、减少同词义槽位碎片化；无命中回退最弱槽。

**读出**：`read()` 返回强度加权平均（按 `strength` 归一），是 `h` 的第二段。
`recall` 也会以 `gate=0.5` 写入 WM——长期记忆的召回结果进入工作记忆。
### 4.5 M4b 大容量事件驱动稀疏表 `SparseLTM`

**脑对应**：海马→皮层的长期记忆，**结构可塑性**（fire together, wire together）。

| 项 | 1B 档值 |
|---|---|
| 大空间神经元数 `big_ltm_N` | **2²⁴ = 16,777,216** |
| 每神经元出边上限 `big_ltm_m` | **72** |
| 每维度哈希神经元数 `big_ltm_k` | 4 |
| **突触容量** | **2²⁴ × 72 = 1,207,959,552 ≈ 1.208e9** |
| 印迹门限 `ltm_imprint_gate` | 0.8（因调制器 z 分布 std≈0.32，实际触发率约 0.4%） |

**两种存储实现**（`csr_online` 切换，`predict`/`learn` 逐位等价）：
`OnlineCSRTable`（**默认**，定长行 + 预留槽，在线可写，≈16 B/条，1B 档实测 5.74× 省）
与 `SparseSynapseTable`（dict 邻接表，≈100+ B/条，短跑/调试用`--no-csr-online`）。

**在线 CSR 的结构可塑性**：`sparse_mmap_dir` 非空 →按分片 mmap 落盘（8 片，按哈希归属）；
行容量 `csr_grow_chunk`（默认 64）预留槽 → 在线追加不需重分配；
`sparse_topk_backprop` > 0 → 稀疏 Top-k 误差反传。

**三个工程要点**（`sparse_table.py`）：① **惰性迹衰减**——触碰时才按 `λ^Δt` 补偿，
避免每步扫描全网；② **pre/post 迹各自独立时间戳**（共用会导致 `Δt=0`、迹无衰减累加爆炸）；
③ **相邻对约定下**新突触生长只由 LTP 驱动，LTD 仅作用于已存在突触。
记忆正比于「被触碰过的神经元」而非 N（2²⁴ 长度数组约 200 MB），
故迹与时间戳也用 dict 按需存储。

**触发逻辑**（`model.py:286`）：

- **imprint**：`mode == "encode"` 且 `mem_gate > 0.8` → 快速印迹。
  大容量表按**稀疏率**印迹（`rate` 本身），而**不是** ±1 稠密码——后者会激活全部
  维度，破坏事件驱动稀疏性（稠密 ±1 会被 `wm.summarize` 的 A2 契约显式拦截）。
- **recall**：`mode == "retrieve"` 且 `step_count % interval == 0`（interval = 8；
  多通道调制下随5-HT 耐心延长）→ 联想补全，召回结果写回 WM。

**接口对齐**：`SparseLTM` 的 `imprint`/`recall` 与稠密 `LongTermMemory` 同接口，
因此 1B 档（`big_ltm=True`）与库默认路径可互换切换。

### 4.6 M5 神经调制 `Neuromodulator` / `MultiModulator`

**脑对应**：蓝斑 NE / 多巴胺的意外信号 + 胆碱能系统的编码-检索切换（Hasselmo）。

```
surprise = ‖e0‖ / √dim        （底层预测误差范数）
z = (surprise − mu) / σ        （Welford 在线标准化，跨步连续）
gate = σ(a·z)                 意外大 → 可塑性开大（先见者学，重复者忘）
mode = "encode" if z > 0.3 else "retrieve"
```

| 通道 | 脑对应 | 作用 | 增益参数 |
|---|---|---|---|
| 单标量（默认） | NE 意外信号 | `gate` 门控全部学习率 | `mod_gain = 1.5` |
| ACh | Hasselmo 编码/检索切换 | 模式门控 | `gain_ach = 1.5` |
| NE | Yu & Dayan 新颖性→可塑性 | 强化 STDP 可塑性增益 | `gain_ne = 2.0` |
| DA | Yu & Dayan 巩固 | 睡眠回放强度 | `gain_da = 1.5` |
| 5-HT | Yu & Dayan 耐心 | 延长检索等待 | `gain_ht = 1.0` |

**多通道模式默认关闭**（`multi_modulation = False` = 单标量旧行为）。

**调制如何进入学习**：`mod_scale = (0.3 + 0.7·gate) · task_scale · cp_scale`
——是**缩放而非开关**（最低保留 0.3），因为完全关断学习会锁死表征。
叠加项：`task_scale`（T1.1 任务误差门控，下限 0.3）、`cp_scale`（临界期经验衰减）。

**T1.1 误差广播调制**：读出 NLL 经 Welford z 标准化 → 门控本步主干学习率，
同时更新**滞后一步**的 `_task_gate` 供下一步记忆写入（T1.3，默认关闭）。

### 4.7 M6 读出头 `Readout`

**脑对应**：IT → 前额叶/前运动皮层的决策读出。**监督信号仅存在于最末端**。

```
h = [r2 ; WM]                    （默认，2·n_top 维）
h = [r2 ; WM ; STDP 预测]        （pred_in_readout，3·n_top = 3072 维，1B 档启用）
y = W·h  →  softmax 感知器  →  交叉熵
W -= (dp ⊗ h)·η                 （dp = p − onehot，rank-1 AXPY 原地更新）
```

1B 档：输入维 `n_h = 3072`（`pred_in_readout=True` → 3×1024）、输出维 = 词表 51,962、
`eta_readout = 0.15`（实测最优区间 0.15–0.20；0.25+ 退化，0.5 发散）、
`--readout-conn-k = 0`（**稠密，主路径**；>0 = CSR 稀疏读出）、
`minibatch_size = 1`（**每步原地更新**）。

**结构可塑性缺口**（承接 §3.2）：`readout_conn_k > 0` 时读出权重以 CSR 承载
（每输出单元 k 条**存在**的入边，复用 `sparse_pc` 的 numba 核），学习规则不变
（仍是 softmax 交叉熵的末端梯度），**变化的只是连接的存在性结构**。
但主路径未启用，**幂律稀疏化方案已设计、未实施**。

**融合更新核**：稠密读出的三步（`outer` → `×η` → `W -=`）融合为**一次对 W 的遍历**
（读+写），按输出行 `prange` 并行。元素级独立（无跨行归约）故 prange 安全，
且运算顺序与 numpy 路径**逐位相同**。这是**纯性能改动、数值逐位等价**，
故不引入行为开关。前向 `y = W·h` **不**换numba 并行核（比 BLAS dgemv 慢且不逐位等价），
仍走 BLAS。

**可选增强**（全部默认关闭）：两级群体读出（`readout_hidden`）、回放稳定读出
（`readout_replay`，储备库保存旧 (输入,目标) 对，每 `replay_every` 步在**当前表征**下
只读前向后重训读出，唯一被写入的是 `readout.W`）、读出再入（`readout_recurrence`，
预测回灌为下一步 WM 线索——皮层反馈再入的抽象，不引入位置编码）、
段内一致性校验（`segment_check`）、读出更新 minibatch 化（`minibatch_size`）、
读出学习率退火（`eta_readout_anneal`/`_floor`）与范数上限（`readout_w_clip`）。

### 4.8 学习规则总表（全部局部，无反向传播）

| 机制 | 规则 | 作用域 | 门控 |
|---|---|---|---|
| M1 编码器 | `ΔW_i = η·s_i·(x − s_i·W_i)` + 范数回拉 | 仅活跃行 | `mod_scale` |
| M2 生成 `W_up` | `ΔW = η·e⊗post` | 仅存在边 | `mod_scale · (1−stability)` |
| M2 识别 `W_dn` | `ΔW = η·(pre − post·w)`（Oja） | 仅存在边 | 同上 |
| M3 STDP | `Δw = η·(P_pre·post − P_post·pre)₊` | 仅拓扑内出边 | `mod_scale · ne_gain` |
| M4a WM | 门控写入 + 漏衰减 | 4 个槽位 | `gate > thresh` |
| M4b 海马印迹 | 相邻对 LTP 驱动**结构生长** | 仅事件触碰 | `gate > 0.8` |
| M4b 皮层巩固 | 快权重 → 慢权重 EMA（`sleep()`） | 已生长突触 | `consolidate_every` |
| M6 读出 | `W -= (p − onehot) ⊗ h · η` | 全矩阵（**欠账**） | `mod_scale · learn_scale` |

**误差信号不跨机制**：读出的 NLL 只通过 M5 的**标量门控**影响 M1–M3 的**学习率**，
不携带方向信息、不反传梯度。这是铁律二「学习规则局部化」的直接体现。

## 5. 认知层：面向 LLM 功能目标的差距声明

PHD-Net 的定位是「提供 LLM 功能所需的**信息原理**」，而非「已实现这些能力」。
机制齐备 ≠ 能力达标：每条原理的实际能力受限于状态容量（1B 档 1.370e9）、
训练数据规模、以及未实施的 M6 稀疏化。

| 能力 | 状态 |
|---|---|
| 下一 token 预测 | 机制齐备（M2 生成-识别 + M3 时序 + M6 读出），能力不足 |
| 长程记忆 / 情景记忆 | 机制齐备（M4b + M4a，`readout_replay` 储备库） |
| 认知层抽象 | 机制薄（仅分层摘要槽） |
| 规划/推理 | ❌ **无对应机制**——架构级缺口，非调参可解 |
| 工具使用 | ❌ **无对应机制** |
| 序列化/JSON 等结构化约束 | 与铁律一（禁位置编码）直接冲突，只能靠词级 SDR 分布式表示间接承载 |

**机制级替代的代价**（不是「不用 attention 的近似」，而是不同信息原理）：
关联由「全局成对相似度」换成「突触迹因果链 + 状态连续演化」（时序泛化未验证）；
记忆由「无学习 KV 缓存」换成「双速率权重」（召回是联想补全，非精确检索）；
抽象由「层堆叠 + FFN」换成「预测编码层级 + 分层摘要」（层级深度有限，4 层）。

跨域泛化是当前主短板（根因是数据 ≫ 架构），详见《竞争力与脑同构性评估》。

（网络抖动指数退避重试，**只重试读取不改数值** → 逐位等价）；
远程分片流式训练（`--remote-fraction`）不整读入内存。

⚠ **已知矛盾（未验证）**：远程分片实测中文仅约 2%、`unk` 约 47%（代码实测），
与文档记录（中文 95%）矛盾 → 需核对数据制备/上传环节。

## 7. 精度体系

### 7.1 读出：`--readout-dtype` 默认 **int8**（fp16 可选）

**三套默认值必须分清**（这是一个反复被混淆的点）：

| 层级 | 默认 | 出处 |
|---|---|---|
| CLI `--readout-dtype`（**生产实际**） | **fp16** | `train/train.py:206`，:476 覆盖到 cfg |
| `PHDNetConfig.readout_dtype`（库默认） | `bf16` | `config.py:293`；仅不经 CLI 直接用库时采用 |
| fp8 forward 副本重建间隔 `--fp8-refresh` | 8 步 | `config.py:201`，摊销量化成本 |

**为什么默认 int8 而不是 fp16/bf16（fhz 2026-10-01）**：int8 码本 1 B/权重（降 4×）。
⚠ int8 权重会吞掉 |dp|≈1e-6 的非目标行更新 → 学习退化，靠饱和裁剪防回绕、靠
fp16/fp32 对照量化幅度；**int16（误差 3e-5）/int32（3e-8，近无损）已就绪**作升档。
**为什么不是 fp8**（历史 P84/P85）：fp8 张量在昇腾（ERR01007）与 CPU（addmv 无实现）
均不可用 → 已废弃，int8 量化码本（uint8 + per-tensor scale）取代其位置：
**为什么默认 fp16（理由是学习精度，不是访存）**：

- bf16 只有 7 位尾数，**半 ULP ≈ 2e-4**；而非目标行更新 `|dp| = |p − 0| ≈ 1e-6`
  → **差两个数量级** → 感知器 `p − t` 的非目标行更新被舍入丢弃
  → 学习规则**退化为「只提升目标行」的纯 Hebbian** → PPL 震荡不降。
- fp16 本机实测 **5,722 个非目标行格点获得更新**（bf16 下为 **0**）。
- **动机不是省访存**：更新侧维持 fp16 主副本 → 总访存反而 **+42%**。
  这是为学习正确性付的代价。

> ⚠ 因此「半精度 PPL 略优」一类**旧语料口径的低精度正则化结论已作废**——
> 它测的是「更新被舍掉后」的行为，不是低精度计算的行为。

**fp8 / fp4 现状**：

| 格式 | 状态 | 说明 |
|---|---|---|
| fp8（e4m3fn） | **在加速器上已禁用为默认** | 服务器实测 `Float8_e4m3fn has not been supported` + ERR01007（昇腾 H2D cast）；CPU 无 fp8 addmv（**能建张量 ≠ 能乘**）→ 探测失败必回落，**等同死代码** |
| fp4（e2m1 + MX 块缩放） | 代码保留，**未启用** | 逐张量缩放不足，需 MX 块缩放；当前禁用 |
| fp16 | **默认** | 昇腾原生 GEMV、访存同 bf16、保住微小更新 |
| bf16 / fp32 | 可显式指定 | `--readout-dtype bf16` / `fp32`（fp32 = 逐位等价的老路径） |

**运行时探测**：fp8 探针必须**探 matmul 而非「能否建张量」**（第一版探针因此漏判）。
**降级必须可见**：CPU 上 fp8 回落 fp16（`tdtype` 同步回落）并告警一次，
启动行 `[readout] compute precision = …` 打印实际精度。

**低精度实现方式**：原生位型码本存储 + 查表反量化；量化用**位算法重量化**
而非二分搜索（搜索版每元素约 15 次比较使更新核计算受限）。softmax/NLL 保持高精度主回路。

### 7.2 M1 编码器：默认 **fp64**（平台自适应）

- `encoder_dtype` 默认 `fp64`（`config.py:299`），**迭代量恒 fp32**
  （GEMV 上采样后计算）；
- **GEMV前必须 `W.dtype == x.dtype`**：混合 dtype（如 fp64 权重 @ fp32 输入）
  会让 numpy 脱离 BLAS 走逐元素慢路径（x86 与 aarch64 上都慢，量级见性能文档 §六）。
  **这是唯一在两个平台都成立的规则。**
- 选 fp64 而非 bf16 的理由：numpy/BLAS 路径下低精度存储每次都要付上采样转换
  （8.4 MB 读 + 16.8 MB 写 + 16.8 MB 读），实测比 fp64 直接 GEMV 更慢。
  bf16 语义在读出侧已由 `readout_dtype` 落地。
- **平台自适应**（`sparse_encoder.py:110`）：aarch64 走自写 numba 核 `_gemv_rows`
  （行间 prange、行内顺序累加，容差 1–2 ulp）；x86 走 BLAS。

### 7.3 分词 onehot 缓冲：fp16

`phdnet/word_encoder.py::onehot()`：预分配**复用 fp16 缓冲**，值只有 0/1 故**无损**。
1B 词表下每步缓冲/传输 289 KB → **208 KB**（配合 `target_idx` 设备路径）。
消费侧（`target_idx` 路径与 softmax）按需要转精度，不受影响。
**复合 SDR 编码** `encode_composite` 用 **fp32** 预分配缓冲（2×n_sdr），
消除每步 `np.concatenate` 分配；语义逐位相同（调用方不持有跨步引用，RL replay 显式 `.copy()`）。

### 7.4 检查点：位模式存储

bf16/fp8 张量**不能直接 `.numpy()`**（numpy 无原生 bf16/fp8）：

| 格式 | 存法 | 加载侧 |
|---|---|---|
| bf16 | **uint16 位模式** | 按 `ckpt_dtype=bf16` + `dtype.kind in "ui"` → `view(bfloat16)` |
| fp8 | **uint8 位模式** | 同上闭环 |

`phdnet/model.py::to_numpy()` 做转换，且**不 import torch**（惰性导入，
否则纯 numpy 训练时会 NameError）。闭环由 `tests/verifiers/verify_ckpt_roundtrip.py` 保证。

⚠ **门禁缺口**：bf16/fp8 的检查点 round-trip **不在 fast 集合内** →
本机全绿、服务器崩（BUGS #34 同族：新增 dtype 必须同步「能力表」+ 断言）。

**词表与可复现性**：词表是**涌现的**，非人工词表——由训练语料采样构建
（`--vocab-sample-chars` 默认 4M，`--vocab-scan full` 全量扫一遍得零 OOV 词表），
SEG 参数 `max_len=6, min_count=5, min_entropy=1.0`。
`--seed`（默认 11）覆盖初始化与词涌现；`--vocab-file` 可复用词表快照
（避免 `--vocab-scan full` 把远程分片整读两遍）。
**词表规模是读出规模的唯一乘数**：读出 `vocab × 3072`，直接决定访存量级；
1B 档实测词表 51,962 → bf16 319.3 MB。
