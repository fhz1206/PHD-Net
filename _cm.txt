P196: Claude Code traces 作为测试训练集（--data cc_traces）

fhz 指定：https://www.modelscope.cn/datasets/choucisan/mimo-claude-code-traces-1k
（1,017 traces / 15,046 events / 11,995 messages / 5,271 tool calls /
10 类 / 40.5 MB / MIT）。

## 数据形态与读取路径
数据集是 **event-stream JSONL**（每行一个 event：user / assistant /
tool_use / tool_result / 元数据），**不是 parquet** —— 通用 iter_texts
找不到 text 字段会得到空流。故新增专用读取路径：

- phdnet/corpus.py：iter_cc_traces / load_cc_traces / cc_trace_to_text
  只抽语言内容、按 event 原顺序还原成对话文本，保留 thinking 块
  （reasoning trace 是这份数据的独特价值）
- corpus.py：远程 .jsonl 直读（ms:// 经 open_ms_file，零落盘）；
  原来对非 parquet 远程源 raise NotImplementedError
- corpus.py：expand_paths 接受已展开的列表（幂等）—— 两级目录
  session/<cat>/*.jsonl 由 train.py 按 10 类逐个展开绕开单层 glob 限制

## train.py 接线
- DATA_FILES 新增 cc_traces；MS_CC_REPO / CC_CATEGORIES 常量
- 远程模式：按类别逐个 expand_ms 合并 + 前缀抽样（ fraction 语义不变）
- 词表构建走 load_cc_traces；full scan 与训练流走 iter_cc_traces
- --data-lang zh 在这份数据上会得空流 → 提前拦下并自动改为不过滤

## 工具
tools/data/cc_traces_to_text.py：--list / --dry-run / --out（转 parquet）
--local-dir / --categories / --per-shard / --no-thinking
